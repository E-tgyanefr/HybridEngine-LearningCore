## 三、我排除掉的（有依据）

| 猜测 | 为什么不成立 |
|---|---|
| "`画列表()` 启动时没被调" | 第 745 行有 `画列表();` |
| "`#副` 的 CSS 把它藏了" | 第 51-52 行只有字号/省略号，**没有 `display:none`** |
| "`#进度` 的 CSS 有问题" | 第 94-96 行是 `display:flex`，正常 |
| "进度条宽度 0% 所以看不见" | 宽度 0% 只能解释**条**看不见，**解释不了文字也没有** |
| "顶栏 `收起` 把它平移走了" | `#顶.收起` 是 `translateY(-100%)`；那是**滚动时才加**的，而截图是**列表页顶部** |
| "进度数据是 0 所以文字为空" | 那会显示 `0/55 · 0%`，**不是空** |

## 四、还没排除的（下一轮该查的）

1. **`副` / `主` 的引用是不是取到了 `null`**
   第 266-269 行那几行 `var` 是**在同一个 `(function(){…})()` 里**，
   但 `#副` / `#主` 的 DOM 在第 244/248 行 —— **位置在 `<script>` 之前**，
   理论上取得到。⚠ 但**没实测**。
2. **有没有 JS 异常把 `画列表()` 打断了**
   `#主` 里的课程列表**渲染出来了**（第 00~05 课都在），
   而 `副.textContent`（第 372 行）在 `h.push('#进度')`（第 378 行）**之前** ——
   如果两个都没生效，那**异常更可能在第 370~372 行之前**（比如 `线课()` 抛了）。
   ⚠ 但那样列表也画不出来…… ⇒ **矛盾，说明我的推断有漏洞。**
3. **顶栏实际高度 vs `--上`**
   `#主` 的 `padding-top: calc(var(--上) + 62px)` 是按"顶栏 62px"算的。
   如果真机上顶栏**比 62px 高**（有 `#副` 那一行时更高），
   那 `#进度` 会被**顶栏盖住** —— 而 `#顶` 若是 `position:fixed` 且背景不透明，
   **盖住的东西完全看不见**。⭐ **这条最像**（能同时解释"副标题也没有"：
   `#副` 在顶栏里，若顶栏被 `translateY` 或高度算错，它同样看不见）。
4. **自检通道能看到答案** —— `?自检=1` 会把
   `有进度 = !!主.querySelector("#进度")`、`进度条在不在`、
   `localStorage 里记了几课`、`有没有 JS 报错` **全写进 `document.title`**，
   宿主 `adb logcat` 能读到。
   ⇒ **这是最直接的查法，下一轮第一件就做它**（发布包首页 URL 没带 `?自检=1`，
   但 `am start -d` 可以带 query，或者临时出一版调试包）。

## 五、诚实结论

- **现象是真的**：真机（发布包，`0.8.0`，`py312.7-chaq-1+6594822`）上
  副标题和进度条**都不显示**，而同一页的标题、课程线、提示框、课程列表**都正常**。
- **原因不明**。我读了三遍代码、排除了 6 个猜测，**没定位到**。
- ⚠ **不能因为"代码看着对"就当成没问题** —— 真机截图为证。
- ⚠ 也**不能因为"进度条没了"就说进度没保存**：
  另一条独立判据是**答题草稿跨重启还在**（实测：强停应用 → 重开 → 第 00 课答题框
  里仍是 60 字）⇒ **localStorage 是工作的**，学员写的东西不会丢。
