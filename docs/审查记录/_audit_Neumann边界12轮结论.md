# 🔬 Neumann 边界：12 轮的完整结论（2026-10-14）

> ⚠ 这一份把散在三个 `.cpp` 文件头里的东西**收成一处** —— 因为**没人会去读文件头**。
> ✅ **第 ⑤ 条已做成**（耦合系统 `[u; z]` ⇒ n=32 误差 **3.87e-06**、实测阶 **3.10**、守恒 2.95e-13）。
> 而 ①~④ 四条路的失败与原因，才是这份账的主体 —— **它们才是"为什么必须不解耦"的证据**。

## 一、一句话结论

```
⭐⭐ **Neumann 的边界通量在"逐点模板"下只能一阶。**

四条"逐点"路我都试了，全部 O(h) —— 那不是巧合，是**格式的性质**，不是笔误。
⇒ ⭐ **要二阶必须"不解耦"**（把紧致关系 `M·u'' = K·u` 当**耦合系统**解）。
```

## 三、⭐「一侧二阶闭合」的真相（最容易被名字骗的一条）

```
公式：`u''(0) ≈ (2u_0 − 5u_1 + 4u_2 − u_3)/h²`  —— 教科书上叫"一侧二阶"
```

### 实测：它**收敛，但只 O(h)**

```
量 (K·u)[0]（u = 1 + cos(πx)）随 h：
   n=5   h=0.25    →  **−13.254834**
   n=9   h=0.125   →  **−11.113854**
   n=17  h=0.0625  →  **−10.208738**
   ⇒ 逐次差 −2.141 / −0.905 ⇒ **比值 2.37 ≈ 2** ⇒ 误差 ∝ **h 的一次方**
   ⇒ 而它**收敛到**精确的 `−π² = −9.869604`（只 O(h)）
截断展开：`u''''(0)/4! · h³ · (−1)` ⇒ **除以 h² 后仍是一次方** ✅ 与实测吻合
```

### ⚠⚠ 而"一侧二阶"这个名字**对 Dirichlet 才是对的**

```
· **Dirichlet** 下：`u_0` 是**已知值** ⇒ 那四项都用得上 ⇒ **二阶** ✅
· **Neumann** 下：它只用到了"`u' = 0` **已经成立**"这件事
  ⇒ 截断里的 `h³` 项**没有被消掉** ⇒ **净 O(h)** ⚠
⇒ ⭐ **"一侧二阶"是 Dirichlet 的性质，被名字带到了 Neumann** —— 那是误导。
```

## 四、⭐⭐「紧致 + 展开」为什么错（一条结构性结论）

```
紧致算子是 **`M·u'' = K·u`（乘积形式）**，
而**不是** `u'' = M⁻¹K·u` 在边界处也**逐点成立**。

⚠ 我把边界行"展开"时（把 `(2/12)u''_1` 也算进第 0 行）：
   `u''_1` 属于**第 1 行的紧致关系** ⇒ 塞进第 0 行 ⇒ **破坏 `M` 的三对角结构**
   ⇒ 实测：矩阵**不对称** + 单步与手算差 1.7e-04 + MAX_REL_ERR 11.3
⇒ ⭐⭐ **正确做法：别展开** —— 把 `M·u'' = K·u` 当**耦合系统**整体离散
⚠ 而那正是 `compact_adi.cpp` **已经做对的事**（它解 `A·u = b`，`A = M ∓ σK`）
   —— **而它只在 Dirichlet 下成立**（边界不进未知量 ⇒ 不破坏三对角）
```

### ⇔ 与 Dirichlet 的结构差异（**这是全局最有用的一句**）

```
**Dirichlet**：边界**不进未知量** ⇒ 展开后仍三对角 + 对称 ⇒ Thomas/CG 都能用 ✅
**Neumann**  ：边界**进未知量**   ⇒ 展开会破坏三对角 ⇒ **必须不解耦** ⚠
⇒ ⭐ **Neumann 与 Dirichlet 的差异不在"公式"，在【结构】。**
```

## 五、⚠ 三次"误差与网格无关"的形态（**症状，不是诊断**）

```
① 虚点法：误差**不随 h 也不随 τ 变**
② 九点反射：误差卡在 2e-3
③ 一侧闭合：误差**在 5 档 h 下逐位相同**（4.930800e-02）
⇒ ⭐ **而每次的根因【不同】**
⇒ ⭐⭐ 所以"逐位不变"只能说明**"有一个与 h 无关的固定项主导"**，
   **不能**告诉你那个固定项是什么 —— **它是症状，不是诊断**。
```

## 六、➡ 唯一可能走得通的那条（**给接手人的具体做法**）

```
⭐⭐ **耦合系统**：未知量 `[u; z]`（`z = u''`），`2n × 2n` 稀疏
    第一块：`R·z = K·u`    ← 紧致关系（`R` = (1/12, 10/12, 1/12)，**边界行按 Neumann 折**）
    第二块：时间推进 `u^{n+1} = u^n + (dt/2)(z^n + z^{n+1})`
    ✅ **两块都对称**（`R` 与 `K` 都是对称三对角）
    ✅ **`GMRES` 已就位**（`sparse.hpp`，判据全绿）
    ⚠ 边界行 `R[0][0]` 从 `10/12` 变成 `11/12`（`u''_{−1} = u''_1` 折进来）
       —— ⭐ 而**这次折叠是对的**（折的是"同一行内"的项，不跨行 ⇒ 不破坏三对角）
```

### ⚠ 而**先把判据顺序用对**（本会话最重要的方法论）

```
① **常数保持**（一步 · 无需解析解 · 无需阶）  ← **最锋利**
② **守恒**（绝热 ⇒ 平均温度恒定）             ← 必要**非**充分
③ **特征值/衰减率**（幂法）                   ← 定量
④ 对齐解析解                                  ← 最贵，且只告诉你"有错"
⚠ 而**① 与 ② 都过、③ ④ 仍红**是常态 ⇒ **"必要条件达成 ≠ 充分条件达成"**
```

### ⚠ 以及**判据设计的两个坑**（本会话各栽过）

```
· ⚠ **"实测阶"必须跨够宽的 h 区间** —— 区间太窄 ⇒ 两项混合 ⇒ 得到"看起来对"的阶
  （我量到 2.19/2.09/2.05/2.02**单调下降** —— 那就是 h¹ 与 h² 在混，我误读成了"二阶"）
· ⚠ **"行和 = 0"只能定总和，定不出对角与邻项的分配**
  ⇒ 它抓得出"反射归错地方"，抓不出"首行多了 u_2"（结构错）
  ⇒ ⭐ **判据的能力边界要说清**
```
