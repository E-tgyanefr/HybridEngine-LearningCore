## 二、⭐ 为什么"并行"和那两句"不做并行"的注释**不矛盾**

⚠ 这是我在动手前**花时间核过**的事 —— 因为公开头里有两句看起来禁止并行的话：

```
nn.hpp:35        //  ⚠ **不做并行**：浮点加法次序一变，"同种子逐位相同"就没了。
autograd.hpp:47  //  ⚠ 反向里**不做任何并行归约** —— 浮点归约次序一变，结果就不逐位相同了。
tensor.hpp:43    //  ❌ **没有**：… `float16`/`bfloat16` · **GPU/并行** · …
```

**逐条判**：
```
① `nn.hpp:35` / `autograd.hpp:47` —— 它们的前提是**有归约**（梯度累加 / 求和）
   ⇒ 对**归约**并行，次序一变就不逐位相同。**那是对的，我没改它们。**
② `tensor.hpp:43` —— 它列在「**❌ 没有**」那一节（"没做什么"），
   与 `docs/AI训练-地基.md` 的"没做什么"一节对应 ⇒ **它是"还没做"，不是"不许做"**
③ 而 `矩阵乘` 按【输出行】分块**没有归约**：
     · 每个输出行 `i` 只写自己的 `c[i*N .. i*N+N)`
     · 行内 `k` 的累加次序、以及 `aik == 0.0` 那条稀疏跳过，**一个字都没改**
   ⇒ **行间互不相干 ⇒ 并行后逐位相同**（而上面 6/6 的逐位比对就是证据）
```

⚠ 而 `tensor.hpp:154` 我**改了**：原文是「**不做**分块/**多线程**/SIMD」⇒ 现在是
  「**不做**分块/SIMD」+ 下面加两个开关的说明。**这是唯一如实改了的一句**。

## 三、设计（三条，都是为了"能被判据钉住"）

```
① **默认串行**（线程数 = 0）⇒ 行为与从前**逐位相同**（`HASH_PARAMS` 没变就是证据）
   并行要显式开：`矩阵乘_设置线程数(n)` —— 与 `hb_raster_set_threads` 同一形态
   理由：这个库的招牌是"同一输入必然逐位相同"，**默认值不该改招牌**
② **主线程也干活**（跑第 0 块），不是只等着 —— 否则 8 条工人 + 主线程空闲 = 白占一个核
③ ⚠ **不用 OpenMP**：它会引入 `libgomp-1.dll`（不在 PATH ⇒ `ctypes.CDLL` 失败
   ⇒ **静默退回 Python**）—— 本仓栽过那次。用标准库 `std::thread`
```

## 四、⚠ 没验到的（逐条）

1. **不同线程数的曲线**（只测了 8）—— 24 核下最优线程数**没找**
2. **小矩阵上的门槛**：N=8/33 时并行**是否反而更慢** —— ⚠ **我测了逐位，没测耗时**
   ⇒ ⭐ 而这一条**必须有**（`task-17` 的教训：小工作量上派发开销会吃掉收益）
3. **Linux / macOS** —— 只在本机 MinGW 编过；`std::thread` 在 POSIX 要链 pthread
   ⚠ 而 `src/ai/CMakeLists.txt` **没有 `Threads::Threads`** ⇒ **CI 上可能链不上**
   ⇒ ⚠⚠ **这一条我必须处理**（否则推上去会把 CI 弄红）
4. **`tensor.cpp` 之外的算子**（求和/softmax 等）—— **没动**（它们**有归约**，不该并）
5. **`-O3` 与 CMake `release-ninja` 完整命令行是否一致** —— 没核
6. **单核效率**：12.502 GFLOP/s 是**朴素 i-k-j 无分块无 SIMD** ⇒ 单核还有空间
   ⚠ **并行只解决"用几个核"，不解决"单核效率"** —— 那是**另一条独立优化**

# 附：Round 24 —— ⚠ 补上门槛（小矩阵上并行慢 **250 倍**）

## ⭐ 规律：并行开销是**固定的 ~0.215 ms**

```
N=16/32/48/64/96 的**并行耗时全部 ≈0.215~0.251 ms（与 N 无关）**
⇒ 那就是**建线程 + join** 的固定成本
⇒ 而串行耗时随 N³ 增长 ⇒ **交叉点必然存在**，位置 = 固定成本 ÷ 单核速度
⇒ **实测交叉点 = 4.19 MFLOP**（约当 N≈126）
```

## 修：**4 MFLOP 门槛**（用"总运算量 M·K·N"而不是"行数"）

| N | 加门槛前 | 加门槛后 | 状态 |
|---|---|---|---|
| 16 | 0.004 | **1.000** | 串行 |
| 96 | 0.554 | **1.043** | 串行 |
| **192** | 2.647 | **2.647** | ⭐ 开始并行 |
| 512 | 6.698 | **6.820** | 并行 |
| 1024 | 6.626 | **6.557** | 并行 |

⇒ **小 N 回到 1.0（无亏损）· 大 N 保持 6.5~6.8x · 逐位相同 12 档全成立** ✅
