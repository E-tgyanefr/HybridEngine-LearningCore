## 一、⭐ 实测数（1280×720，无限速、无 vsync、逐档负载）

工具：`C:\gs_link\gpu_stress.cpp`（我写的探针，**用仓库的静态库链**，见第三节）
编译：`g++ -std=c++17 -O2 -I include gpu_stress.cpp libhybridengine_{render3d,platform,core}.a -ld3d11 -ldxg -ld3dcompiler ...`

### 怎么读这张表

```
⭐ **饱和吞吐 ≈ 2.2~3.1×10⁷ 三角形/秒**（2K~256K 区间基本平）
   ⇒ **这才是 GPU 的真实极限**
⚠ 16/256 两档的 ms/帧 **反而更小** ⇒ 那是"帧太小、被 1280×720 的固定开销主导"
   （清屏 + 呈现），**不是 GPU 快** —— 读表时别把它当成"低负载更快"
⚠ 262,144 那档 12.09 ms/帧 = 83 帧/秒 ⇒ **单独看这一档就是 12 倍的 60 帧预算**
   ⇒ 也就是说：**专业版 GPU 在 60 帧下能画 ~190,000 个三角形/帧**
```

### ⚠ 这份数的边界（必须一起看）

```
· 网格是**静态**的（每档同一个 MeshData，每帧重复 Submit 同一个）⇒ 测的是**提交+光栅化**，
  **不含**骨骼动画/蒙皮/每帧重建顶点缓冲
· 只用**一个 draw call**（整个网格一次 Submit）⇒ **不含** draw call 开销
  ⇒ ⚠ 真实场景是"多个对象各一次 Submit"，那个数会不同（可能差很多）
· 没有纹理（`TextureRef` 默认空）⇒ 不含采样开销
· 1280×720 一个分辨率 ⇒ 不含分辨率扫描
· 单次测量，**没取中位数**
```

## 二、⚠⚠ 而我为这份数**连着踩了三个坑**（都值得记）

| # | 我下的结论 | 真因 |
|---|---|---|
| 1 | 「另一个编译器，ABI 不兼容」 | ⚠ **是同一个 MinGW**（`CMakeCache` 里的编译器路径与我的一模一样） |
| 2 | 「`nm` 读不到导出表」 | ⚠ **MinGW 的 `ar`/`nm`/`ld` 处理不了中文路径**（`引擎`→`????`）⇒ 换 ASCII **立刻读出 2550 个符号** |
| 3 | 「该用静态库，但链不上（符号问题）」 | ⚠ **还是中文路径** —— `ld` 报的是 `cannot find ...\����\...libhybridengine_render3d.a: No such file or directory` |

⇒ ⚠ **三个坑里有两个是同一个原因（中文路径）**，而我**第三次才发现**。

### ⭐ 而顺带查到一条**真事实**（不是坑，是本仓的设计）

```
那个 dll 里**一个 C++ 符号都没有**：
   `GpuRenderer` 0 · `_ZN12HybridEngine` 0 · `CreateWindow` 0
   （`ms_*` C ABI 符号有 2550 个）
⇒ **它只导出 C ABI** —— 完全符合设计（`ms_bind.h` 是给外部用的唯一接口）
⇒ ⚠ **所以拿 dll 链 C++ 类永远链不上** —— 那**不是** ABI 问题，是**它不对外导出 C++**
⇒ ⭐ **链 C++ 必须用静态库**（`build-*/src/*/libhybridengine_*.a`，共 14 个模块）
```

## 三、✅ 可复现的构建方法（**这条本身是交付**）

```
① 把 `include/` 和需要的 `.a` 拷到 **ASCII 路径**（⚠ 关键！MinGW 的 ld 读不了 `引擎`）
      C:\gs_link\include\   （69 个头文件）
      C:\gs_link\lib\libhybridengine_render3d.a · _platform.a · _core.a
② g++ -std=c++17 -O2 -I include -o gs.exe gpu_stress.cpp \
       lib/libhybridengine_render3d.a lib/libhybridengine_platform.a lib/libhybridengine_core.a \
       -ld3d11 -ldxgi -ld3dcompiler -luser32 -lgdi32 -lole32 -lwinmm
⇒ 退出码 0 · 249,748 B
备用（前两轮踩过的）：
   · **不要**用 `libhybridengine.dll.a` 链 C++（只有 C ABI）
   · **不要**用 `build/release`（09-24 的旧产物，缺 `ms_save_set_path`）
```
