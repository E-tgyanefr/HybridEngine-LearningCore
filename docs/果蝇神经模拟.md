## 一、规格：学习内核**只做果蝇**，不做人脑

作者的原话是「**学习内核只能运行果蝇神经模拟**」。这是**规格**，不是能力不足
的借口。分工是这样的：

| 线的分工 | 模拟对象 | 规模 |
|---|---|---|
| **学习内核**（本模块 + 第 55 课） | **果蝇** | 约 **10⁵** 个神经元 |
| 通用神经模拟（另一条线，`neural.py`） | 人脑 | 约 **8.6×10¹⁰** 个神经元 |

**为什么这样分** —— 三个理由，都是可以拿手验的：

1. **能给新手看懂。** 果蝇的神经元能一个一个给编号、画在纸上；
   860 亿个画不出来，只能讲"平均场"那种抽象量。
   ⇒ 学习内核的读者是**新手**，所以它必须停在"看得见"的那一层。
2. **能在这台机器上真跑。** 本模块默认 240 个神经元 × 200 步，
   实测 **0.03 秒**跑完 —— 学员改一个参数立刻能看到变化（这就是"做实验"）。
   同样"逐细胞"地跑人脑，差的不是快慢，是**十个数量级**。
3. **果蝇本来就是神经科学的模式生物。** 它是少数几个**全脑连接组被完整测出来**
   的动物之一 —— 讲神经计算，果蝇是有真数据撑腰的最小例子。

⇒ **一句话**：想学"网络怎么发放、抑制怎么压住兴奋"，用这一课；
想看"人脑级规模长什么样"，那属于通用神经模拟那条线。

## 三、⚠⚠ 本模块的连接矩阵是**程序化生成**的，不是真实连接组

这句话必须在最显眼的地方说清楚：

> **本模块里的连接是随机生成的，不是果蝇的真实连接组。**

理由：真实连接组是几个 GB 的点云重建结果，要联网下载、要专门的工具读；
而本仓的铁律是**零第三方依赖 + 离线可跑** ⇒ 拿不到，也不该塞进来。

生成规则（`造连接`）：

```
· 神经元 0 ~ 0.8N-1 是兴奋性；其余 0.2N 是抑制性
· 每一对 (甲, 乙)、甲≠乙，以 `连接概率` 的概率连一条 甲→乙 的边
· 权重只看**发出去的那个人**：兴奋 ⇒ +0.09，抑制 ⇒ -0.35
· 随机数来自 random.Random(f"{种子}-连接")（本模块自己的流）
```

**它能演示什么 / 不能演示什么**：

    ✅ 能演示   网络动力学：稀疏放电、抑制作为刹车、确定性
    ❌ 不能演示 任何关于**真实果蝇**的结论（这张网和真果蝇没有对应关系）

想用真数据：FlyWire / Hemibrain 都是公开的，见第二节那三条出处。

## 四、模型：一个神经元 = 一个会漏水的桶（LIF）

```
(1) v_k(t+1) = v_k(t) · 漏电 + 输入_k(t)
(2) 输入_k    = 外部敲的 + 上一步**发放了的**神经元传来的权重之和
(3) v_k ≥ 阈值  ⇒  记一次发放、v_k ← 0
```

· `漏电` = 0.85 < 1 ⇒ 不给输入时电位自己漏回 0（这就是 *leaky*）
· 兴奋权重是**正**的（油门）、抑制权重是**负**的（刹车）
· 这就是神经科学里的 **LIF**（leaky integrate-and-fire）。
  上面 Shiu et al. 2024 那篇 *Nature* 建**全脑**模型用的也是这一层 ——
  所以这不是"给小孩看的简化版"，是正经方法的一个小号实例。

命令行（改参数最直接的方式，**不需要写代码**）：

## 六、headless · 确定性 · 零依赖

| 要求 | 怎么满足的 | 怎么验的 |
|---|---|---|
| **零第三方依赖** | 只 import `random` / `dataclasses`（+ 函数内 `sys`） | `tests/test_果蝇.py` 用 **AST** 数 import，不靠肉眼 |
| **headless** | 模块**从头到尾不 import 任何图形库**，不开窗口 | 同一份测试断言源码里没有 `import tkinter/matplotlib/PIL/pygame/numpy` |
| **确定性** | 所有随机数来自本模块**自己的** `random.Random(f"{种子}-用途")`；造连接和外部输入是**两条独立的流** | 同种子两次 ⇒ 每步放电数**逐位相同**；换种子 ⇒ 不同 |
| **版本首位 0** | 模块里 `版本 = "0.1.0"` | —— |

⚠ "两条独立的随机流"这个设计是有用的：换"输入"的种子时**不会**把网络结构也换掉，
对照实验才干净（见 `抑制对比`）。

## 七、实测数据（这一轮真跑出来的）

### 7.1 默认参数下的动力学

```
步数 200 · 平均放电率 0.0545（每步约 13.1 个神经元发放）
总放电 2617（兴奋 2090 / 抑制 527）
边数 4626（理论期望 240×239×0.08 = 4589）
兴奋 192 个 / 抑制 48 个
用时约 0.03 秒
```

### 7.2 ⭐ 抑制真的是刹车

同一张网、同一份输入，**只把抑制关掉**：

| | 平均放电率 |
|---|---|
| 有抑制（`抑制强度=1.0`） | **0.0545** |
| 没抑制（`抑制强度=0.0`） | **0.4305** |
| | **7.90 倍** |

⇒ 没有刹车，这张网会**烧起来**（43% 的神经元每步都在发放）。
有抑制时稳定在 **5.45%** 的稀疏放电 —— 真实大脑也是这个状态：
**少数人在说，多数人在听**。

### 7.3 连接概率扫描（这张表的值钱之处）

| 连接概率 | 有抑制 | 没抑制 |
|---|---|---|
| 0.00 | 0.0801 | 0.0801 |
| 0.02 | 0.0633 | 0.0801 |
| 0.08 | 0.0550 | 0.4142 |
| 0.15 | 0.0690 | 0.9628 |
| 0.30 | 0.1002 | 0.9828 |

⚠ 这张表暴露了一件事：**"放电率落在合理区间"这一条判据抓不住"边造了却不用"**——
没有传播的实现，放电率照样落在区间里（外部输入自己就能把神经元敲响）。
⇒ 所以第 55 课加了一条**更硬**的判据：**把连接概率从 0.08 换成 0.30，结果必须变**
（0.0550 → 0.1002，差 45%）。没有传播的实现两次会**一模一样** ⇒ 当场被抓住。
反面对照里那条"造了边却不传播"的错答案，就是被这一条抓住的。

## 九、⚠ 顺手发现的四件事（都不在我的写盘范围，交给 Lead）

### 9.1 ⭐⭐ 判据报的「4 课不过」是**它自己的假失败** —— 那 4 课全过

`_verify_reference_all.py` 用 **`报.count("×")`** 数失败 —— 那是**全串计数**。
而 `×` 在中文里还是**乘号**，那 4 课的**检查名字里就带 `×`**：

```
课 45   六棵树 × 三种遍历都对（含空树、单节点、满树、缺孩子、斜树）
课 46   八组都对（含空迷宫、起点=终点、走不通、一行、50×50 全空 98 步）
课 48   6 组都和暴力枚举一致（含 1×1、单行、单列）
课 50   3×3 的 512 种网格全试过，一块都没数错
```

实测每课报告里 `×` 出现的位置：

| 课 | 全串 `×` | **行首** `×` | 判定 |
|---|---|---|---|
| 45 | 1 | **0** | **假失败** |
| 46 | 1 | **0** | **假失败** |
| 48 | 1 | **0** | **假失败** |
| 50 | 1 | **0** | **假失败** |

单独跑课 45 的检查，报告是 **`全部通过（4/4）`**。

⇒ **python 线的真实结果是 `56 过 · 0 不过`**（55 课 + 本课），不是 52/4。

**建议的修法**（一行）—— 把「全串计数」换成「**行首判据**」：

```python
错 = sum(1 for l in 报.split("\n") if l.strip().startswith(("✗", "×")))
```

⚠ 这和 2026-10-14 那个假绿是**同一类**：判据拿**子串**去认一个其实是**行首记号**
的东西。行首记号一个都没有 ⇒ 应当判「**没跑到**」，而不是"过"。
