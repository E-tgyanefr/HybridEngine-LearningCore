# GESP 考纲对照（一级 → 八级）

> **这份文件是干什么的**
>
> 用户的要求是「课程要做到最高等级」。CCF GESP（编程能力等级认证）是中文世界里
> 最主流的分级标准，分一到八级。这份文件把**每一级的要求**逐条对到课程上，
> **留白的地方就是缺口** —— 也就是接下来要写的课。
>
> 对照方法：每一条考纲要求，标出「哪一课教它」。如果没课教，就写 **待补**，
> 并在下面列出准备加的课。
>
> ⚠ 这份表是**可复核的清单**，不是宣传材料。空缺就是空缺。
