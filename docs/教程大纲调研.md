|---|---|---|---|

⇒ **零基础选后者**（指针放数组/字符串之后）。本项目的 C 课就是按这个排的。

### 初学者最常犯的错（按知识点）

- **01**：`void main()`；漏分号/用**全角分号**报一堆莫名错误；`mian`
- **02**：用未初始化变量（打印随机"垃圾值"）；`5/2` 得 2；`int` 装小数静默截断
- **03**：以为 `#define` 要分号；宏不加括号导致 `SQUARE(x+1)` 展开错
- **04**：`a & b == c` 优先级搞混；同一条语句里混用 `i++`/`++i`；`==` 写成 `=`
- **05**：格式符与参数类型不匹配（`%d` 打 double）；`scanf` 忘了 `&`；
  `scanf("%c")` 读到上一次的换行符
- **06**：`if (a = 1)` 条件恒真；`if (a > b);` 多打分号；悬空 else
- **07**：漏 `break` 意外贯穿；在 `case` 里声明变量没加 `{}`
- **08**：off-by-one（`i <= n` 与 `i < n`）；循环里重新声明累加器
- **09**：条件永远真 → 死循环；`do-while` 末尾漏分号
- **10**：以为 `break` 能跳出多层嵌套；`continue` 跳过了变量更新造成死循环
- **11**：以为改形参能改到实参（**C 是按值传递**）；原型与定义签名不一致；漏 `return`
- **12**：漏基准情形 → 栈溢出；用递归算斐波那契 → 指数级重复计算
- **13**：越界不报错；在函数内用 `sizeof(a)/sizeof(a[0])` 求长度（已退化成指针）
- **14**：忘 `'\0'`；用 `==` 比字符串、用 `=` 赋值（应 `strcmp`/`strcpy`）；
  `char s[5] = "hello"` 装不下终止符
- **15**：解引用未初始化的野指针；`*p++` 与 `(*p)++` 混淆；返回局部变量的地址
- **16**：`p.name` 与 `p->name` 用错；定义后忘分号；直接对结构体用 `==`

### 最容易卡住的三处（按顺序）

1. **工具链与第一次编译运行** —— 大量人卡在第 0 课就放弃
2. **循环与状态变化的心智模型** —— 从"顺序执行"切到"重复 + 每轮改写"
3. **指针与内存** —— 公认最大分水岭

### 初学者最常犯的错（摘）

- **02**：读未初始化变量（UB，值随机）；`cin >> x` 失败后不处理流状态
- **03**：有符号与无符号混算，负数变巨正数；用 `==` 比较浮点数
- **04**：以为 `const` 一定是编译期常量（该用 `constexpr`）；
  `string_view` 指向已销毁的临时字符串 → 悬垂
- **06**：`if (x = 5)` 赋值当比较；`switch` 漏 `break`
- **08**：局部变量遮蔽全局；头文件里定义非 inline 全局变量 → 重复定义
- **09**：以为按值传参能改到实参；默认实参在声明和定义里**重复给出**
- **10**：返回局部变量的引用/指针；`const int*` 与 `int* const` 分不清
- **13**：成员初始化列表**按声明顺序**执行，不是书写顺序；
  需要深拷贝时没写拷贝构造 → double free
- **14**：基类析构函数没写 `virtual`；按值传派生对象 → **对象切片**
- **15**：遍历中 `erase`/`push_back` → 迭代器失效；
  `size() - 1` 无符号下溢；lambda 按值捕获想改外部却没加 `mutable`
- **16**：模板定义放 `.cpp` → 链接错误；`catch` 按值捕获；
  `catch` 把基类放在派生类之前 → 永远匹配不到

### 最容易卡住的三处

1. **编译/链接错误的信息量与心智模型** —— `undefined reference` vs `syntax error`
2. **值语义 vs 引用语义** —— "拷贝一份"与"绑定到同一个对象"两套语义
3. **类与对象的所有权/生命周期** —— 构造析构顺序、拷贝何时发生、虚析构

### 来源分歧（重要）

1. **数组放哪里**：Oracle 放 Language Basics（紧跟 primitive、**在运算符之前**）；
   《Java核心技术》放第 3 章末尾；中文高校大纲与"分支/循环"并列。
2. **构造器与继承的先后**：中文大纲与《Java核心技术》是"先构造器/this/static 再继承"；
   **《Head First Java》反过来**（继承第 7 章、接口第 8 章、构造器直到第 9 章）。
3. **泛型与集合**：Oracle 单列在继承之后；Head First 压到第 16 章；中文大纲紧随 OOP 之后。
4. **异常处理**：Oracle 主 trail **没有**独立异常课（在 Essential Classes）；
   《Java核心技术》第 7 章；中文大纲第 7 章；Head First 第 11 章。
5. **lambda / Stream 是否进前 16**：Oracle 老教程与中文大纲基本不收；《Java核心技术》第 6 章已含。
6. **GUI（Swing）是否必修**：中文高校大纲普遍必修（大连理工给了 3 单元 + 3 次实验），
   而 Oracle 现代教程与英文主流教材**基本不再教**。← **中英文来源最大的结构性分歧**

### 初学者最常犯的错（摘）

- **01**：源文件名与 public 类名不一致；混淆 `javac` 与 `java`（写成 `java App.class`）
- **02**：`float pi = 3.14;` 漏 `f`；局部变量未初始化就用 → "might not have been initialized"
- **03**：`5/2` 得 2 不是 2.5；`=` 与 `==` 混用；`i++` 与 `++i` 取值时机
- **04**：`switch` 漏 `break`；用 `==` 比较字符串内容（应 `equals`）
- **05**：`i <= arr.length` 越界；`while` 条件里写成赋值 `=`；忘记更新循环变量
- **06**：**以为 Java 是引用传递**（只有值传递）；重载与覆写混为一谈
- **07**：`ArrayIndexOutOfBoundsException`；声明了却没 `new`；以为数组能动态加元素
- **08**：声明引用后没 `new` 就调用成员 → `NullPointerException`；
  一个 `.java` 里写多个 public 类
- **09**：绕过 getter 直接改字段；字段与参数同名却不写 `this.size = size`
- **10**：给构造器写了返回值类型；`this()` 没放第一行；自定义构造器后以为无参构造器还在
- **11**：静态方法里访问实例变量；以为 `final` 修饰引用后对象内容也不可变
- **12**：覆写时参数写错变成重载；覆写时**降低访问权限**；父类引用调子类特有方法
- **13**：想 `extends` 多个类；忘记实现全部抽象方法；在接口里定义实例字段
- **14**：`catch` 后既不处理也不记日志（吞异常）；父类异常写在子类前面；
  `finally` 里 `return` 覆盖原返回值
- **15**：用 `==` 比较 String；**foreach 中 add/remove** → 抛异常；
  字符串转数字不处理 `NumberFormatException`
- **16**：流/连接用完不关；classpath 与包目录不匹配 → `ClassNotFoundException`

### 最容易卡住的三处

1. **类 / 对象 / 引用三者的区别** —— "声明 ≠ 创建"，`NullPointerException` 出自这里
   （中文高校大纲为此单排 5 个教学单元，是课时最重的一块）
2. **继承 → 多态 → 抽象类 → 接口这条链** —— 覆写与重载、向上转型后"能调用哪些方法"
3. **值传递 + 字符串不可变 + equals 语义** —— 为什么改不动实参、为什么要用 `equals`

10 类与对象                    —— 字段、属性、构造器、对象初始化器、静态成员

### 来源分歧（重要）

1. **《C# in Depth》不能当零基础顺序用** —— 它按语言版本组织，作者明说
   "readers are already expected to know the first version"。只能当进阶查漏表。
2. **模式匹配的位置**：官方入门教程排在第 6 课（**在类与对象之前**）；传统教材放 OOP 之后。
3. **类型种类 vs 面向对象**：官方 "Tuples and types" 排第 3 课，且自己提示
   "Coming from another language? You can skim tutorials 1–2"。
4. **集合的位置**：官方 List collection 排第 5 课，**早于类与对象**；传统教材放 OOP 之后。
5. **入门程序形态**：官方现在默认 file-based app + 顶层语句（没有 class、没有 Main），
   传统教材用 `class Program { static void Main }`。
6. **委托与事件**：中文大纲常合成一章作为 OOP 基本技术；
   官方基础路径不列为入门必修，而是用 `Func<>`/`Action<>` + lambda 讲。

### 初学者最常犯的错（摘）

- **01**：C# 区分大小写，`console.writeline` 直接编译失败；
  一个项目里多个文件都写顶层语句（官方只允许一个）
- **02**：把 `bool` 当整数（官方原文 "in C#, bool isn't convertible to int"）；
  值类型与引用类型赋值语义搞混；右侧类型不清晰时仍用 `var`
- **03**：`13 / 5` 得 2（官方：整数相除向零取整）；
  用 `==` 比较浮点（官方示例 `0.1 * 3 == 0.3` 输出 **False**）；金额该用 `decimal`
- **04**：循环里用 `+=` 拼大量字符串（官方要求用 StringBuilder）
- **06**：`i <= list.Count` 越界；在 `foreach` 里修改集合
- **08**：以为返回类型不同就能构成重载；以为参数默认引用传递
- **09**：不理解 `record` 是**值相等**而 `class` 默认引用相等
- **10**：用 public 字段代替属性；**以为无参构造器永远存在**
  （一旦自定义构造器就没有了，官方专门讲了这点）
- **11**：记错默认访问级别（**类成员默认 private**，官方 object-oriented 页明确）
- **12**：该写 `override` 却写 `new` → 变成隐藏而非覆写；
  派生类构造器没写 `: base(...)` → 编译失败
- **15**：`catch (Exception)` 后既不处理也不重抛（官方："Don't catch an exception
  unless you can handle it"）；`throw ex;` 而不是 `throw;`（丢堆栈）；
  资源没用 `using` 释放
- **16**：`switch` 表达式漏兜底分支；**误以为 LINQ 已执行**（延迟执行）

### 最容易卡住的三处

1. **类型系统本身** —— 值类型 vs 引用类型、struct/class/record 取舍、可空性
2. **面向对象语义** —— 属性 vs 字段、`virtual/override/new` 的区别、
   构造器链 `: base(...)`、访问修饰符默认值
3. **泛型集合 + 模式匹配 / LINQ 的"查询式"思维** —— 延迟执行与模式匹配的语法密度

## 六、这份调研对我们课程的结论

### 6.1 五门语言的**共同骨架**（高度一致的部分）

```
变量与类型 → 运算符 → 输入输出 → 分支 → 循环 → 函数 → 数组/集合 →
字符串 → （C 系：指针/结构体）（OOP 系：类与对象 → 封装 → 继承 → 接口）→ 异常
```

**这个骨架与本来已经写好的课程是一致的** —— Python 16 课、C 16 课都落在上面。

### 6.2 调研**证实**的两个决定

1. **C：指针放数组与字符串之后** —— learn-c.org 与浙大翁恺都是这个顺序（K&R 更早，
   但那本书面向有经验的人）。本项目的 C 课正是这么排的。
2. **C++：`std::string` 早、容器晚** —— 折中了 C++ Primer（早用标准库）
   与 learncpp（先打语言基础）两套哲学。

### 6.3 调研**指出**的缺口（要改的地方）

| 缺口 | 依据 | 影响 |
|---|---|---|
| 浮点数误差要**提前**讲 | Python 官方放到第 15 章，但零基础第 3 课就撞上 `0.1+0.2` | Python 课第 03 课 |
| 每门语言都该有**第 0 课：工具链与第一次编译** | C/C++ 两边都把"卡在第 0 课"列为头号放弃原因 | 五门语言都缺 |
| `switch`（多分支）在 C 里是**独立**一课 | K&R / learn-c.org / 浙大课都单列，因为"贯穿"语义是个坑 | C 课缺 |
| `while` / `do-while` 与 `for` 分开 | 三份 C 大纲都分开讲 | C 课合在一起了 |
| `const` / `constexpr` 值得独立 | learncpp 有独立的常量章，且 `constexpr` 是 C++ 特有坑 | C++ 课缺 |
| 作用域与生命周期（C++ 第 08 课） | learncpp 单列整章 | C++ 课缺 |
| 递归 | C/C++ 大纲都单列 | 两门都缺 |
| Java 的 `static`/`final`、构造器、接口 | Oracle 各占独立 lesson | Java 只有 8 课，缺得多 |
| C# 的元组/结构/记录、模式匹配/LINQ | 官方入门教程明确收录 | C# 只有 8 课，缺得多 |
