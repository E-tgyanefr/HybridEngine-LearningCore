模板|// ⚠⚠ **JDK ≠ JRE** —— 这是这一课最重要的一句话：
模板|//
模板|//      JRE = Java Runtime Environment   只能**运行**别人编好的程序
模板|//      JDK = Java Development Kit       = JRE + **javac 编译器** + 工具
模板|//
模板|//   只装 JRE 的话，`java` 有、`javac` 没有 —— 而你要自己写代码，必须要 javac。
模板|//
模板|// ─────────────────────────────────────────────────────
模板|//  二、Java 的程序结构和别的语言不一样
模板|// ─────────────────────────────────────────────────────
模板|//
模板|//  ① **不能有游离的代码。** 每一样东西都必须装在一个**类**里面。
模板|//
模板|//        Python 可以:   print("hi")                    ← 文件顶层直接写
模板|//        C 可以:        int main() { printf(...); }    ← 函数里直接写
模板|//        Java 不行:     必须 类 → 方法 → 语句，一层套一层
模板|//
模板|//  ② **入口方法长这样**，一个字都不能错：
模板|//
模板|//        public static void main(String[] args) { ... }
模板|//
模板|//  ③ **public 的类名必须和文件名一致**（区分大小写）。
模板|//
模板|//        文件叫 Main.java  ⇒  类必须叫 public class Main
模板|//
模板|//  这一条**别的语言都没有**。C 的 main 是小写的函数，
模板|//  而 Java 的 main 是方法、类才是外壳 —— 别把两件事混起来。
模板|//
模板|// ─────────────────────────────────────────────────────
模板|//  三、Java 比 C 多一层：字节码
模板|// ─────────────────────────────────────────────────────
模板|//
模板|//      Main.java
模板|//         ↓  javac Main.java     编译器
模板|//      Main.class                 **字节码**（不是机器码）
模板|//         ↓  java Main           JVM 解释执行
模板|//
模板|// ⚠ 运行的时候写的是 **java Main**：一个**类名**，不带任何后缀。
模板|//
模板|//      java Main             ✓
模板|//      java Main.class       ✗ 错误: 找不到或无法加载主类 Main.class
模板|//
模板|// ─────────────────────────────────────────────────────
模板|//  四、这一课唯一要练的手艺：读第一条 error
模板|// ─────────────────────────────────────────────────────
模板|//
模板|// 报错长这样（这是**故意写错**的代码）：
模板|//
模板|//      Main.java:5: 错误: 需要';'
模板|//          System.out.println("你好")
模板|//                                 ^
模板|//      1 个错误
模板|//
模板|// 拆开看：**哪个文件、第几行、什么错**。先看行号。
模板|//
模板|// 两条铁律：
模板|//
模板|//   ① **只看第一条 error。** 后面那几十条多数是它引起的连锁反应。
模板|//   ② **报错行号常常要往上多看一行。** 编译器是读到「它不认识的东西」
模板|//      才报的错，而那个东西往往是**上一行**漏了什么造成的。
模板|//
模板|// ⚠ 本机是中文环境，javac 的报错就是中文的（`错误: 需要';'`）。
模板|//   换一台英文环境的机器，同样的错会写成 `error: ';' expected` ——
模板|//   **是同一件事**，别被语言吓住。
模板|//

答案|/* 这一课练的是「读报错」—— 先故意漏一个分号编译一次，读完报错再补回来。
答案|
答案|   报错大概长这样：
答案|       Main.java:5: error: ';' expected
答案|   意思是「第 5 行这里我以为该有个分号」。
答案|
答案|   ⚠ 如果报错是「类 Main 是公共的, 应在名为 Main.java 的文件中声明」，
答案|     那是**类名和文件名不一致** —— Java 特有的规矩。
答案|
答案|   程序结构是三层：类 → 方法 → 语句。
答案|   Java 里没有「游离的代码」，任何一行都必须待在这三层里面。 */
答案|public class Main {
答案|    public static void main(String[] args) {
答案|        System.out.println("工具链就绪");
答案|        System.out.println("我准备好学 Java 了");
答案|        System.out.println("类 → main → 语句");
答案|    }
