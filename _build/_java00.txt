@@@ 00_跑通第一个程序
标题|第 00 课：跑通第一个程序 —— 把 JDK 装好
要求|1. 确认 javac / java / dotnet 都在（本课会真的去调它们）
要求|2. 搞清楚 Java 的程序结构和别的语言哪里不一样
要求|3. 让编译器报一次错，并且学会从第一条 error 读起
模板|// 第 00 课：跑通第一个程序 —— 把 JDK 装好
模板|//
模板|// ⚠⚠ 这一课**不教语法**，只干一件事：让你这台机器真的能编译、能运行。
模板|//
模板|//    为什么把它排在第 00 课：
模板|//      Java **不是"装上就能跑"的语言** —— 它要 JDK，而网上大量教程
模板|//      让人装的是 JRE。**JRE 里没有 javac**，于是他永远编不过，
模板|//      还找不到原因。这一步值得单独占一课。
模板|//
模板|// ─────────────────────────────────────────────────────
模板|//  一、需要什么（两样，都是免费的）
模板|// ─────────────────────────────────────────────────────
模板|//
模板|//  ① .NET SDK  —— "课程运行器"。它替你调 javac 和 java，并跑起来看结果。
模板|//
模板|//        winget install Microsoft.DotNet.SDK.8
模板|//
模板|//     ⚠ 要的是 **SDK**，不是 Runtime —— Runtime 里没有编译器。
模板|//
模板|//  ② JDK       —— Java 的开发包。**不是 JRE。**
模板|//
模板|//        winget install Microsoft.OpenJDK.21
模板|//
模板|//     或者去 https://adoptium.net 下 Temurin。
模板|//
模板|//     装完**重开一个窗口**（让 PATH 生效），然后敲这两条：
模板|//
模板|//        javac -version
模板|//        java  -version
模板|//
模板|//     两条都能看到版本号才算成。
模板|//
模板|//  ⚠⚠ **JDK ≠ JRE** —— 这是这一课最重要的一句话：
模板|//
模板|//        JRE = Java Runtime Environment    只能**运行**别人编好的程序
模板|//        JDK = Java Development Kit        = JRE + **javac 编译器** + 工具
模板|//
模板|//     只装 JRE 的话，`java` 有、`javac` 没有 ——
模板|//     而你要**自己写代码**，就必须要 javac。
模板|//     报错会是「找不到 javac」或者「不是内部或外部命令」。
模板|//
模板|// ─────────────────────────────────────────────────────
模板|//  二、Java 的程序结构：和 C 完全不同的三点
模板|// ─────────────────────────────────────────────────────
模板|//
模板|//  ① **不能有游离的代码。** 每一样东西都必须装在一个**类**里面。
模板|//
模板|//        Python 可以:   print("hi")                    ← 文件顶层直接写
模板|//        C 可以:        int main() { printf(...); }    ← 函数里直接写
模板|//        Java 不行:     必须 类 → 方法 → 语句，一层套一层
模板|//
模板|//  ② **入口方法长这样**，一个字都不能错：
模板|//
模板|//        public static void main(String[] args) { ... }
模板|//        ↑      ↑      ↑    ↑      ↑
模板|//        公开   静态   无返回 方法名  参数（一个字符串数组）
模板|//
模板|//     少了 static ⇒ 程序起不来。这是 Java 新手最常卡的第一处。
模板|//
模板|//  ③ **public 的类名必须和文件名一致**（区分大小写）。
模板|//
模板|//        文件叫 Main.java  ⇒  类必须叫 public class Main
模板|//        写成 public class main  ⇒ 编译报错
模板|//
模板|//     这一条**别的语言都没有**。C 的 main 是小写的函数，
模板|//     而 Java 的 main 是方法、类才是外壳 —— 别把两件事混起来。
模板|//
模板|// ─────────────────────────────────────────────────────
模板|//  三、Java 比 C 还多一层：字节码
模板|// ─────────────────────────────────────────────────────
模板|//
模板|//        Main.java
模板|//           ↓  javac Main.java        ← 编译器
模板|//        Main.class                    ← **字节码**（不是机器码！）
模板|//           ↓  java Main               ← JVM 解释执行
模板|//        结果
模板|//
模板|//  C 编译出来的是**你这台机器的机器码**（换台机器就跑不了）。
模板|//  Java 编译出来的是**字节码**，由 JVM 在运行时翻译 ——
模板|//  所以同一份 .class 在 Windows、Linux、Mac 上都能跑。
模板|//
模板|//  ⚠ 注意运行的时候写的是 **java Main**，
模板|//    **不是** `java Main.class`、**也不是** `java Main.java`。
模板|//    这是 Java 新手第二个常卡的地方。
模板|//
模板|// ─────────────────────────────────────────────────────
模板|//  四、这一课唯一要练的手艺：读第一条 error
模板|// ─────────────────────────────────────────────────────
模板|//
模板|//  Java 的报错长这样（这是**故意写错**的代码）：
模板|//
模板|//      Main.java:5: error: ';' expected
模板|//          System.out.println("你好")
模板|//                                 ^
模板|//      1 error
模板|//
模板|//  拆开看：哪个文件、**第几行**、什么错。先看行号。
模板|//
模板|//  ⚠⚠ **两条铁律**：
模板|//
模板|//   ① **只看第一条 error。** 后面那几十条多数是它引起的连锁反应。
模板|//      一个没写对的括号能让编译器抱怨一整屏。
模板|//
模板|//   ② **报错行号常常要往上多看一行。** 编译器是读到"它不认识的东西"
模板|//      才报的错，而那个东西往往是**上一行**漏了什么造成的。
模板|//
模板|//  ⚠ Java 的报错里还有一个**中文**提示要注意：
模板|//
模板|//        错误: 类 Main 是公共的, 应在名为 Main.java 的文件中声明
模板|//
模板|//    这是"类名和文件名不一致"。Java 特有的，看到它就去改类名。
模板|//
模板|// ─────────────────────────────────────────────────────
模板|//  轮到你了
模板|// ─────────────────────────────────────────────────────
模板|//
模板|//  这一课没有算法要写，只有三件事：
模板|//
模板|//    1. 确认 javac、java、dotnet 都在
模板|//       （界面首页的「环境自检」会显示；命令行敲 javac -version 也行）
模板|//
模板|//    2. 让编译器**报一次错**，并且读懂它
模板|//       下面留了一个完整的程序。先故意漏掉一个分号 → 检查 → 看报错 →
模板|//       把分号补上 → 再检查。
模板|//
模板|//       为什么要你故意写错一次：**报错是编译器在跟你说话**。
模板|//       第一次被它骂过的人，第二次才不慌。
模板|//
模板|//    3. 让它打印出下面这三行，就算跑通了
模板|//
模板|//          工具链就绪
模板|//          我准备好学 Java 了
模板|//          类 → main → 语句
模板|//
模板|// ─────────────────────────────────────────────────────
模板|//  怎么自己测
模板|// ─────────────────────────────────────────────────────
模板|//  这一课在界面上点「检查」就行。
模板|//  命令行（如果你在源码目录里）：
模板|//
模板|//      dotnet run --project csharp/java-lessons -- 检查 00
模板|//
模板|//  卡住了？把报错连同你的代码发出去问，比空想快得多。
模板|
模板|// ── 在下面写你的代码 ──
模板|
模板|public class Main {
模板|    public static void main(String[] args) {
模板|        System.out.println("工具链就绪");
模板|        /* ⚠ 先故意把下面这一行的分号删掉，检查一次，看看 javac 怎么说。
模板|           读完报错再把分号补回来。 */
模板|        System.out.println("我准备好学 Java 了");
模板|        System.out.println("类 → main → 语句");
模板|    }
模板|}
答案|/* 这一课练的是「读报错」—— 先故意漏一个分号编译一次，读完报错再补回来。
答案|
答案|   报错大概长这样：
答案|       Main.java:5: error: ';' expected
答案|   意思是「第 5 行这里我以为该有个分号」。
答案|
答案|   ⚠ 如果报错是「类 Main 是公共的, 应在名为 Main.java 的文件中声明」，
答案|     那是**类名和文件名不一致** —— Java 特有的规矩。
答案|
答案|   程序结构是三层：类 → 方法 → 语句。
答案|   Java 里没有「游离的代码」，任何一行都必须待在这三层里面。 */
答案|public class Main {
答案|    public static void main(String[] args) {
答案|        System.out.println("工具链就绪");
答案|        System.out.println("我准备好学 Java 了");
答案|        System.out.println("类 → main → 语句");
答案|    }
答案|}
检查|程序能编译、能跑起来（说明 javac / java 都就绪）|输出逐行|工具链就绪|我准备好学 Java 了|类 → main → 语句
检查|类名与文件名一致（public class Main）|代码包含|public class Main
检查|入口方法写对了（public static void main）|代码包含|public static void main
检查|用的是 System.out.println（Java 的打印方式）|代码包含|System.out.println
