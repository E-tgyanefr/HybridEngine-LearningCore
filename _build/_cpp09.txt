标题|第 09 课：const 与 constexpr —— 承诺不改，和编译时就算好
要求|1. 用 const 写一个函数 int 圆周长的百倍(int 半径)，里面用 const int 圆周率的百倍
要求|2. 用 constexpr 定义一个编译期常量 格子数，并用它给一个数组定长度
模板|// 第 09 课：const 与 constexpr —— 承诺不改，和编译时就算好
模板|//
模板|// 先介绍：`const` 和 `constexpr` 长得很像，但不能互换
模板|//
模板|//     const       **我承诺不改它**（运行时的常量）
模板|//     constexpr   **编译的时候它就已经是一个确定的数了**（编译期常量）
模板|//
模板|//  每个 constexpr 都是 const，但**反过来不成立**：
模板|//
模板|//     int 读一个数();                        // 运行时才知道
模板|//     const int a = 读一个数();               // ✅ 合法：承诺不改
模板|//     constexpr int b = 读一个数();           // ❌ 编译不过：编译时算不出来
模板|//
模板|//  判据很简单：**这个值在编译的时候能不能算出来？**
模板|//
模板|// ─────────────────────────────────────────────────────
模板|// ─────────────────────────────────────────────────────
模板|//  用法与例子
模板|// ─────────────────────────────────────────────────────
模板|
模板|//  一、`const`：把"不该改"写进代码里
模板|// ─────────────────────────────────────────────────────
模板|//
模板|//     const double 圆周率 = 3.14159;
模板|//     圆周率 = 3.14;              // ❌ 编译报错：assignment of read-only variable
模板|//
模板|//  它挡住的是一类具体的事故：**手滑改了一个本该固定的值**。
模板|//  比如税率、圆周率、最大人数 —— 改错了程序照样跑，只是结果全错。
模板|//  让编译器替你记住"这个不许改"，比靠人记住可靠得多。
模板|//
模板|//  ⚠⚠ **`const` 到底锁住了什么（这一课最容易搞错的一处）：**
模板|//
模板|//        const int* p;          // p **指向的 int** 不能改；p 自己能改（换指向）
模板|//        int* const p = &x;     // p **自己**不能改（不能换指向）；指向的能改
模板|//        const int* const p = &x;   // 两个都不能改
模板|//
模板|//     读法：**从右往左读** —— `const int* p` 读作
模板|//     "p 是一个指针，指向 const int"。
模板|//     这不是"指向的东西和指针本身都不能改"，很多人第一反应会读错。
模板|//
模板|//  ⚠ 和 `#define`（C 那边的做法）比：`const` **有类型**，
模板|//    所以编译器能帮你检查类型、调试器里也能看见它。
模板|//    C++ 里**优先用 const / constexpr，不要用 #define 定义常量**。
模板|//
模板|// ─────────────────────────────────────────────────────
模板|//  二、`constexpr`：让编译器替你算
模板|// ─────────────────────────────────────────────────────
模板|//
模板|//     constexpr int 边长 = 4;
模板|//     constexpr int 面积 = 边长 * 边长;      // 编译器**当场算出 16**
模板|//
模板|//  好处有两个：
模板|//
模板|//     ① 这个计算**不用等程序跑起来**，编译时就做完了（快一点）
模板|//     ② 它能用在**必须编译时确定**的地方 —— 比如数组长度：
模板|//
模板|//            int 格子[边长 * 边长];          // ✅ constexpr 可以
模板|//            const int n = 读一个数();
模板|//            int 格子[n];                    // ❌ 标准 C++ 里不行（那是运行时才知道的）
模板|//
模板|//  ⚠⚠ **这就是 const 和 constexpr 最实用的一条分界线。**
模板|//     需要"用它来定数组长度"的时候，必须 constexpr。
模板|//
模板|//  ⚠ 顺便记住：`const` 变量**也可能**是编译期常量（如果初值就是字面量），
模板|//    但语言**不保证**这一点 ⇒ 要"保证"，就得写 constexpr。
模板|//    这条区别在 C++ 面试里也常问。
模板|//
模板|// ─────────────────────────────────────────────────────
模板|//  三、什么时候用哪个（一条实用判据）
模板|// ─────────────────────────────────────────────────────
模板|//
模板|//     初值是字面量、而且我要拿它定数组长度或做别的编译期计算  → constexpr
模板|//     初值要运行时才知道（读文件、读传感器、算出来）           → const
模板|//     只是函数参数，保证函数里不改它                          → const（放在参数上）
模板|//
模板|//  ⚠ 一个常见误解："用了 const 程序会变快。"
模板|//    不会 —— const 是**给编译器和给人看**的约束，不是性能开关。
模板|//    真正省时间的是 constexpr（把计算挪到编译期）。
模板|//
模板|// ─────────────────────────────────────────────────────
模板|// ─────────────────────────────────────────────────────
模板|//  常见坑
模板|// ─────────────────────────────────────────────────────
模板|// ⚠ 坑 1：给 const 变量赋值
模板|//
模板|//     const int 圆周率的百倍 = 314;
模板|//     圆周率的百倍 = 315;               ← 想改它
模板|//
模板|// 你会看到（g++ 原文，实测）：
模板|//     main.cpp:5:18: error: assignment of read-only variable '\U00005706…'
模板|// 为什么：const 就是「只读」的意思，赋值直接编译不过。
模板|// ⚠ 那一长串转义就是「圆周率的百倍」—— g++ 会把中文标识符转义成这种样子。
模板|//
模板|// ⚠ 坑 2：用 constexpr 装一个「运行时才知道」的值
模板|//
模板|//     int 读一个数() { return 5; }
模板|//     constexpr int b = 读一个数();
模板|//
模板|// 你会看到（g++ 原文，实测）：
模板|//     error: call to non-'constexpr' function 'int …()'
模板|// 为什么：constexpr 的初值必须**编译期就能算出来**，
模板|//   而调用一个普通函数要等程序跑起来才知道结果（哪怕它永远返回 5）。
模板|//   ⇒ 这种值用 `const int b = 读一个数();`。
模板|//
模板|// ⚠ 坑 3：拿「运行时才知道的 const」去定数组长度
模板|//
模板|//     const int n = 读一个数();
模板|//     int 格子[n];
模板|//
模板|// 你会看到：**g++ 居然不报错** —— 实测它能编过、还能跑
模板|//   （-std=c++17 -Wall 一声不吭）。只有加 -pedantic 才会说：
模板|//     warning: ISO C++ forbids variable length array [-Wvla]
模板|// 为什么：g++ 把这种数组当成「变长数组」的**扩展**放过去了 ——
模板|//   但标准 C++ 里数组长度必须是编译期常量，换别的编译器就直接编译不过。
模板|// ⚠ 这一条最误导人：**编译器不拦你，不代表写法是对的。**
模板|

模板|//   ① int 圆周长的百倍(int 半径)
模板|//      函数**里面**定义 `const int 圆周率的百倍 = 314;`
模板|//      返回 2 × 圆周率的百倍 × 半径 ÷ 100（整数运算，正好整除）

模板|//
