## 4. ⚠ 没验的（**逐条**）

| 项 | 为什么 |
|---|---|
| Linux 上打 tar.gz / AppImage / .deb | 没有 Linux；PyInstaller 交叉编译不了 |
| macOS 上打 `.app` / `.dmg` | 没有 macOS；`build_macos_app.sh` 的组装段**一次都没执行过** |
| `.app` 双击能不能开（Gatekeeper / 公证） | 同上 |
| Linux/macOS 上解压后的 x 位 | Windows 没有 x 位 |
| `.deb` 依赖声明对不对 | 没打过真包 |
| `_check_platform.py` 在 Linux/macOS 上的实际输出 | 没在那些平台跑过 |
| **`_retag.py` / `_rebuild_versions.py` 改完能不能跑** | ⚠ 它们会**打 GitHub API 建 release** ⇒ 跑了就等于 push。只做了 `py_compile` |
| 专业版 HybridEngine 的任何构建 | 不在本任务范围（另有安排） |
| CI 会不会绿 | 跑不了 GitHub Actions |
| SampleCore 的构建/测试 | 本任务没跑（另有 owner 记录） |
