模板|//
模板|// 前面几课你已经在忍受这件事了。想表示"一个点"（有 x 和 y），
模板|// 你得用两个变量：

模板|//  用法与例子
模板|// ─────────────────────────────────────────────────────
模板|//
模板|// ① 定义、创建、访问

要求|1. 用 vector<int> 存 {5, 2, 9, 1}，打印它的 size()

模板|// 第 13 课：vector 与常用算法 —— 会自己变长的数组
模板|//
模板|// 先介绍：数组那个"长度必须写死"的毛病
模板|//
模板|// 第 06 课你已经知道数组的硬伤：
模板|//
模板|//     int 数们[5];               ← 长度写死
模板|//     数们[5] = 6;                ← ✗ 越界，而且**不报错**（这是最坏的）
模板|//
模板|// 现实里的"一串数"很少能预先知道有几个：读文件、用户输入、
模板|// 筛选结果……于是实际代码里到处是"猜一个大一点的数"：
模板|//
模板|//     int 数们[1000];            ← 猜
模板|//     int 个数 = 0;              ← 还得自己记用了几个
模板|//
模板|// C++ 的答案叫 **vector**：一个**会自己变长**的数组。
模板|//
模板|//     #include <vector>
模板|//     std::vector<int> 数们;      ← 空的，长度 0
模板|//     数们.push_back(5);          ← 加一个，长度变成 1
模板|//     数们.push_back(2);          ← 长度 2 … 想加多少加多少
模板|//
模板|// ⚠ 它和数组**用法几乎一样**（都用 `[]` 取元素），但三件事变好了：
模板|//     ① 长度自己长 —— 不用猜、不用自己记个数
模板|//     ② `数们.size()` 随时问得出长度
模板|//     ③ 出了 `<algorithm>` 那一堆现成算法可以用（排序、查找、求和…）
模板|//
模板|// ─────────────────────────────────────────────────────
模板|//  用法与例子
模板|// ─────────────────────────────────────────────────────
模板|//
模板|// ① 建、加、取、问长度
模板|//
模板|//     #include <vector>
模板|//
模板|//     std::vector<int> 数们 = {5, 2, 9, 1};   ← 直接花括号初始化
模板|//     数们.push_back(7);                       ← 加到末尾
模板|//     数们.size()                              ⇒ 5     ⚠ 是**方法**（有括号）
模板|//     数们[0]                                  ⇒ 5     ⚠ 下标从 0 开始
模板|//     数们.at(0)                               ⇒ 5     ← 会检查越界（[] 不检查）
模板|//
模板|//   ⚠ `size()` 返回的类型是 `size_t`（无符号整数）。
模板|//     拿它和 `int i` 比较时编译器会警告"有符号/无符号比较"。
模板|//     这一课用 `for (int i = 0; i < (int)数们.size(); i++)` 强制转一下就好。
模板|//
模板|// ② 两种遍历
模板|//
模板|//     旧的（按下标）：
模板|//         for (int i = 0; i < (int)数们.size(); i++)
模板|//             printf("%d\n", 数们[i]);
模板|//
模板|//     新的（范围 for，C++11 起）—— 更短，而且**不会写错边界**：
模板|//         for (int 数 : 数们)
模板|//             printf("%d\n", 数);
模板|//
模板|//     ⚠ 想**改**元素要加 `&`：
模板|//         for (int& 数 : 数们) 数 *= 2;      ← ✓ 真的改了
模板|//         for (int  数 : 数们) 数 *= 2;      ← ✗ 改的是副本，白改
模板|//

模板|//
模板|//     #include <algorithm>
模板|//     #include <numeric>          ← accumulate 在这里，不在 algorithm！
模板|//
模板|//     std::sort(数们.begin(), 数们.end());         ← 从小到大
模板|//     std::reverse(数们.begin(), 数们.end());      ← 反转
模板|//     std::accumulate(数们.begin(), 数们.end(), 0) ⇒ 总和（第三个参数是初值）
模板|//     std::max_element(数们.begin(), 数们.end())   ⇒ **指向**最大元素的迭代器
模板|//
模板|//   ⚠ 每个算法都要给一对"从哪到哪"：`begin()` 和 `end()`。
模板|//     `end()` **不是**最后一个元素，而是"最后一个元素的**下一个**位置"
模板|//     —— 这是 C++ 的标准约定（叫"半开区间"），记住"end 是越界的那个"。
模板|//
模板|// ⚠ `accumulate` 在 `<numeric>` 里，不在 `<algorithm>` 里 ——
模板|//   这是很多人第一次用的时候的"找不到符号"。用到它就两个头文件都 include。
模板|//
模板|// ─────────────────────────────────────────────────────
模板|//  常见坑
模板|// ─────────────────────────────────────────────────────
模板|//
模板|// ⚠ 坑 1：对空的 vector 排序 / 取元素
模板|//
模板|//     std::vector<int> 空;
模板|//     std::sort(空.begin(), 空.end());      // ✓ 其实没问题（空区间）
模板|//     printf("%d\n", 空[0]);                // ✗ 未定义行为
模板|//
模板|// `空[0]` **不会**报错，它会读一块不属于你的内存 —— 可能打印个垃圾数，
模板|// 可能崩，也可能"看起来正常"。这是 C++ 里最危险的一类错。
模板|// 用 `空.at(0)` 会抛异常（至少你知道出事了），或者先判 `空.empty()`。
模板|//

模板|//
模板|//     for (int 数 : 数们) {
