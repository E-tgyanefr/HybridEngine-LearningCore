# 给「写课」子代理的契约（它们必须照这个写，我负责转换与验证）

## 为什么要把契约写死

课程文件是**生成**出来的：`_build/_gen_compiled.py` 读数据文件产 `.cs`。
子代理直接写 `.cs` 有三个必踩的坑：

1. **检查形态有限**（15 种），写错了生成器**不报错**，只会生成一条
   "永远不过"的检查 —— 症状看起来像"学员答错了"，其实是课坏了。我踩过。
2. **Java 的类声明必须在最前** —— 参考答案若以注释开头，
   课程运行器找不到 `public class Main`（我用参考答案跑出来才发现）。
3. `printf` 的格式符要跟返回类型对上：`%d` 打整数、`%s` 打 C 字符串。
   错了会**冤枉正确答案**（我在这上面栽过两次）。

⇒ 所以子代理**只交内容**（讲解 / 参考答案 / 检查规格），
   由我转换成数据文件、生成、构建、跑正反验证。
