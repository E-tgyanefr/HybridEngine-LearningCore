模板|//           int i=1   i <= 5      i++
模板|//
模板|//   · 初始化：循环开始前做一次
模板|//   · 继续条件：每轮开始前检查，**为假就停**

模板|//
模板|// 累加的套路（和 Python 一样，但**必须先初始化**）：
模板|//     int 和 = 0;              ← ⚠ 忘了这行，和会是随机的垃圾值
模板|//     for (...) 和 += x;
模板|//
模板|// ⚠ C 里未初始化的局部变量**不会自动是 0** —— 它是内存里的随机值。
模板|//   这是 C 与 Python 的又一个大区别。
模板|//
模板|// ─────────────────────────────────────────────────────
模板|//  轮到你了 —— 在下面写
模板|// ─────────────────────────────────────────────────────
模板|//   写函数：  int 求和到(int n)
模板|//   返回 1 + 2 + ... + n
模板|//

模板|//   求和到(0)  ⇒ 0
模板|//
模板|// 提示：不用写 main。
模板|
