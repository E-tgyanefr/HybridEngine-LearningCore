标题|第 01 课：printf —— 让程序开口说话
要求|1. 打印一行文字：你好，C
要求|2. 打印一个整数：42
要求|3. 最后一行打印：完成
模板|// 第 01 课：printf —— 让程序开口说话
模板|//
模板|// ─────────────────────────────────────────────────────
模板|//  先介绍：C 程序的骨架
模板|// ─────────────────────────────────────────────────────
模板|//
模板|//   C 程序**一定**长这个样子，少一样都编译不过：
模板|//
模板|//       #include <stdio.h>          ← 头文件：printf 需要它（stdio = standard input/output）
模板|//
模板|//       int main(void) {            ← 主函数：程序从这里开始跑
模板|//           ...                     ← 你的代码
模板|//           return 0;               ← 告诉系统"正常结束"
模板|//       }
模板|//
模板|// 三件必须记住的事：
模板|//   ① 每条语句末尾要有**分号** ;    （漏了会报 expected ';'）
模板|//   ② 代码块用**花括号** { }        （C 不看缩进，看括号）
模板|//   ③ 打印用 printf("...")          （f = formatted，格式化输出）
模板|//
模板|// 换行要在引号里面写 \n —— 它不是"两个字符"，是一个换行符。
模板|//   想打「你好」再换行：   printf("你好\n");
模板|//
模板|// ─────────────────────────────────────────────────────
模板|//  用法与例子
模板|// ─────────────────────────────────────────────────────
模板|//
模板|//  ① 打印一段固定文字：把内容放在双引号里。
模板|//
模板|//      printf("你好，C\n");
模板|//
模板|//  ② 打印一个值：先用**格式符**占个位，再把值写在逗号后面。
模板|//
模板|//      printf("%d\n", 42);
模板|//
模板|//      %d 就是"这里放一个整数"。逗号后面的 42 会填进去。
模板|//
模板|//  ③ 一行里放多个值：占位符和值的**顺序一一对应**。
模板|//
模板|//      printf("%d 加 %d 等于 %d\n", 1, 2, 3);      ⇒ 1 加 2 等于 3
模板|//
模板|//  ④ 常用的四个格式符（这一课先记 %d 和 %s，后面几课都会用到）：
模板|//
模板|//      %d    整数          int
模板|//      %f    小数          double
模板|//      %s    字符串        char*
模板|//      %c    单个字符      char
模板|//
模板|//  一个完整的、能跑的例子：
模板|//
模板|//      #include <stdio.h>
模板|//
模板|//      int main(void) {
模板|//          printf("你好，C\n");
模板|//          printf("%d\n", 42);
模板|//          printf("完成\n");
模板|//          return 0;
模板|//      }
模板|//
模板|//  输出（三行）：
模板|//
模板|//      你好，C
模板|//      42
模板|//      完成
模板|//
模板|//  ⚠ 注意输出里**看不到** `%d`，也看不到 `\n`：
模板|//      %d 被 42 替换掉了，\n 变成了一个真正的换行。
模板|//
模板|//  ⚠ 如果不写 \n，两次 printf 的输出会挤在同一行：
模板|//      printf("你好，C");    printf("完成");
模板|//      ⇒ 你好，C完成
模板|//
模板|// ─────────────────────────────────────────────────────
模板|//  常见坑
模板|// ─────────────────────────────────────────────────────
模板|//
模板|//  ⚠ 坑 1：漏了 #include <stdio.h>
模板|//
模板|//      错误写法：
模板|//          int main(void) {
模板|//              printf("你好\n");
模板|//              return 0;
模板|//          }
模板|//
模板|//      你会看到什么（gcc 原文，下面的横线是编译器画的，原文里是竖线）：
模板|//
模板|//          main.c:2:5: error: implicit declaration of function 'printf' [-Wimplicit-function-declaration]
模板|//              2 │     printf("你好\n");
模板|//                │     ^~~~~~
模板|//          main.c:1:1: note: include '<stdio.h>' or provide a declaration of 'printf'
模板|//
模板|//      为什么：printf 不是语言自带的关键字，它只是 stdio.h 里**声明**的一个函数。
模板|//      编译器从上往下读，读到 printf 时没见过它，只好猜"它大概返回 int" ——
模板|//      这个"猜"就是 implicit declaration（隐式声明）。
模板|//      现代 C（C99 以后）已经把这个"猜"当成错误了。
模板|//      ⇒ 看到这条，第一反应永远是：**头文件写了吗？**
模板|//
模板|//  ⚠ 坑 2：格式符和值的类型对不上
模板|//
模板|//      错误写法（用 %d 去打印字符串）：
模板|//
模板|//          printf("%d\n", "你好");
模板|//
模板|//      你会看到什么（gcc 原文）：
模板|//
模板|//          main.c:3:14: warning: format '%d' expects argument of type 'int', but argument 2 has type 'char *' [-Wformat=]
模板|//              3 │     printf("%d\n", "你好");
模板|//                │             ~^     ~~~~~~
模板|//                │              │     │
模板|//                │              │     │
模板|//                │              │     char *
模板|//                │              int
模板|//                │             %s
模板|//
模板|//      运行时你看到的不是报错，而是**一个莫名其妙的整数**（内存地址）：
模板|//
模板|//          267931728
模板|//
模板|//      为什么：%d 告诉 printf"把这段内存当成一个 int 来解释"，
模板|//      而 "你好" 是 char*（字符串第一个字符的地址）。
模板|//      它照做了 —— 于是你得到一个地址，而不是你想要的文字。
模板|//      ⚠ 好消息：gcc 会**警告**你，而且最后那行 `%s` 就是它给你的改法。
模板|//      ⇒ **warning 要读，它经常直接告诉你该换成哪个格式符。**
模板|//
模板|//  ⚠ 坑 3：把 \n 写成了 /n，或者漏了分号
模板|//
模板|//      错误写法：
模板|//          printf("你好/n");          /* 斜杠方向反了 */
模板|//
模板|//      你会看到什么：编译**通过**，但屏幕上真的印出「你好/n」四个字。
模板|//
模板|//      为什么：反斜杠 `\` 才叫"转义符"。`/` 只是个普通的斜杠字符，
模板|//      C 不认识 `\n` 以外的写法，就把它原样打出来。
模板|//
模板|//      另一种更吵的错误 —— 漏分号：
模板|//
模板|//          printf("你好，C\n")
模板|//          return 0;
模板|//
模板|//          main.c:3:17: error: expected ';' before 'return'
模板|//              3 │     printf("你好，C\n")
模板|//                │                 ^
模板|//                │                 ;
模板|//                │     return 0;
模板|//                │     ~~~~~~
模板|//
模板|//      为什么：编译器读到 `return` 时才发现上一句没说"结束"。
模板|//      ⚠ 报的是**第 3 行**，但该补分号的是**第 2 行** —— 往上多看一行。
模板|//
模板|// ─────────────────────────────────────────────────────
模板|//  轮到你了 —— 在下面写
模板|// ─────────────────────────────────────────────────────
模板|//   1. 打印一行文字：你好，C
模板|//   2. 打印一个整数：42
模板|//   3. 最后一行打印：完成
模板|//
模板|// 提示：完整程序，要自己写 #include 和 main。
模板|//
模板|// ⚠ 期望输出（三行，一字不差）：
模板|//
模板|//      你好，C
模板|//      42
模板|//      完成
模板|//
模板|// ─────────────────────────────────────────────────────
模板|//  怎么自己测
模板|// ─────────────────────────────────────────────────────
模板|//   点界面上的「检查」。
模板|//   命令行：dotnet run --project csharp/c-lessons 检查 01
模板|//   看这一课要干什么：dotnet run --project csharp/c-lessons 01
模板|//   看答案：dotnet run --project csharp/c-lessons 答案 01
模板|//

要求|1. 定义 int 变量 年龄 = 18
要求|2. 定义 int 变量 学号 = 7
要求|3. 打印这两个变量（分两行）
模板|// 第 02 课：变量 —— 给一个值起个名字
模板|//
模板|// ─────────────────────────────────────────────────────
模板|//  先介绍：变量 = 给一个值起个名字
模板|// ─────────────────────────────────────────────────────
模板|//
模板|//     int 年龄 = 18;
模板|//     ↑   ↑     ↑
模板|//    类型  名字  值
模板|//
模板|// ⚠⚠ **C 和 Python 最大的区别就在这里：C 必须先说类型。**
模板|//
模板|//     Python：  年龄 = 18              不用写类型
模板|//     C：       int 年龄 = 18;         必须写 int
模板|//
模板|// 为什么：C 是**编译型**语言，编译时要为每个变量分配固定的内存大小，
模板|// 所以它必须知道你打算装什么。这也让 C 跑得很快。
模板|//
模板|// 这一课只用 int（整数）。小数（float/double）在第 04 课。
模板|//
模板|// ⚠ 常见的错：
模板|//     年龄 = 18;              ❌ 没写类型 ⇒ 报 undeclared identifier
模板|//     int 年龄 = 18           ❌ 漏了分号 ⇒ 报 expected ';'
模板|//     int 年龄 = 18;          ✅
模板|//
模板|// 打印变量和打印常量一样，都是 printf：
模板|//     printf("%d\n", 年龄);   ← %d 是"这里放一个整数"的占位符
模板|//
模板|// ─────────────────────────────────────────────────────
模板|//  用法与例子
模板|// ─────────────────────────────────────────────────────
模板|//
模板|//  ① 声明并赋值（这一课只用这一种写法）：
模板|//
模板|//      int 年龄 = 18;          声明的同时给初值
模板|//
模板|//  ② 声明和赋值也可以分开写：
模板|//
模板|//      int 年龄;               先声明
模板|//      年龄 = 18;              后赋值
模板|//
模板|//      ⚠ 中间那一小段时间里，年龄是**未初始化的**，
模板|//        它的值是内存里的随机垃圾（第 07 课会专门讲这个）。
模板|//        ⇒ 能一行写完就一行写完。
模板|//
模板|//  ③ 变量可以参与运算，也可以被重新赋值：
模板|//
模板|//      int 甲 = 17;
模板|//      甲 = 甲 + 1;            ⇒ 18     右边先算，再存回左边
模板|//
模板|//  ④ 打印变量：格式符要和类型对上，int 就用 %d。
模板|//
模板|//      printf("%d\n", 年龄);
模板|//
模板|//  一个完整的、能跑的例子：
模板|//
模板|//      #include <stdio.h>
模板|//
模板|//      int main(void) {
模板|//          int 年龄 = 18;
模板|//          int 学号 = 7;
模板|//          printf("%d\n", 年龄);
模板|//          printf("%d\n", 学号);
模板|//          return 0;
模板|//      }
模板|//
模板|//  输出（两行）：
模板|//
模板|//      18
模板|//      7
模板|//
模板|//  ⚠ 名字的规则：字母、数字、下划线都行，**但不能用数字开头**，
模板|//    也不能和关键字重名（int、return、if 这些）。中文名字 C 允许，
模板|//    这门课大量用它，因为读起来最像你想的事情。
模板|//
模板|// ─────────────────────────────────────────────────────
模板|//  常见坑
模板|// ─────────────────────────────────────────────────────
模板|//
模板|//  ⚠ 坑 1：忘了写类型
模板|//
模板|//      错误写法：
模板|//          int main(void) {
模板|//              年龄 = 18;
模板|//              return 0;
模板|//          }
模板|//
模板|//      你会看到什么（gcc 原文，中文名字会被它转义成 UCN 码点）：
模板|//
模板|//          main.c:2:5: error: '\U00005e74\U00009f84' undeclared (first use in this function)
模板|//              2 │     年龄 = 18;
模板|//                │     ^~~~
模板|//          main.c:2:5: note: each undeclared identifier is reported only once for each function it appears in
模板|//
模板|//      为什么：`\U00005e74\U00009f84` 就是「年龄」两个字的 Unicode 码点 ——
模板|//      gcc 在报错信息里把非 ASCII 名字转义了，**它说的就是你的变量名**。
模板|//      "undeclared" = 我没见过这个名字 ⇒ 因为你没告诉它类型。
模板|//      ⚠ 看报错时不要被 `\U...` 吓到，把它当成你写的中文名字读。
模板|//
模板|//  ⚠ 坑 2：漏了分号 —— 而且报错会指向**下一行**
模板|//
模板|//      错误写法：
模板|//          int 年龄 = 18
模板|//          printf("%d\n", 年龄);
模板|//
模板|//      你会看到什么（gcc 原文）：
模板|//
模板|//          main.c:3:17: error: expected ';' before 'printf'
模板|//              3 │     printf("%d\n", 年龄);
模板|//                │                 ^
模板|//                │                 ;
模板|//
模板|//      为什么：编译器一路读下去，直到撞见 `printf` 才发现
模板|//      "上一句还没结束"。所以它**在第 3 行报错，错在第 2 行**。
模板|//      这就是第 00 课那条"往上多看一行"的铁律。
模板|//
模板|//  ⚠ 坑 3：用 %d 打一个没赋值的变量
模板|//
模板|//      错误写法：
模板|//          int 得分;
模板|//          printf("%d\n", 得分);
模板|//
模板|//      你会看到什么：
模板|//          .\main.exe: 程序能编译、能运行，但打印出来的是个随机数
模板|//          （每次跑可能还不一样）
模板|//
模板|//      为什么：C 里**局部变量不会自动清零**（这点和 C# 不一样，

模板|//      地上原来有什么就还是什么。
模板|//      ⇒ 换个编译器、换个编译选项，这个随机数还会变。
模板|//      这类 bug 最难受的地方是"代码看着完全正确"。
模板|//      ⚠ 记住这条：**声明变量的时候顺手就给初值。**
模板|//
模板|// ─────────────────────────────────────────────────────
模板|//  轮到你了 —— 在下面写
模板|// ─────────────────────────────────────────────────────
模板|//   1. int 变量 年龄 = 18
模板|//   2. int 变量 学号 = 7
模板|//   3. 分两行打印它们
模板|//
模板|// ⚠ 期望输出（两行，一字不差）：
模板|//
模板|//      18
模板|//      7
模板|//
模板|// ⚠ 检查还会看你的源码里有没有真的写 `int 年龄` 和 `int 学号` ——

模板|//   看答案：dotnet run --project csharp/c-lessons 答案 02
模板|//

@@@ 03_算术
标题|第 03 课：算术 —— 让程序算起来
要求|1. 定义 int 甲 = 17、int 乙 = 5
要求|2. 打印 甲 / 乙（整数除法，看结果是多少）
要求|3. 打印 甲 % 乙（取余）
模板|// 第 03 课：算术 —— 让程序算起来
模板|//
模板|// ─────────────────────────────────────────────────────
模板|//  先介绍：C 的五个运算符
模板|// ─────────────────────────────────────────────────────
模板|//
模板|//     +   加      3 + 2   ⇒ 5
模板|//     -   减      3 - 2   ⇒ 1
模板|//     *   乘      3 * 2   ⇒ 6
模板|//     /   除      7 / 2   ⇒ 3        ← ⚠ 两个整数相除，结果还是整数！
模板|//     %   取余    7 % 2   ⇒ 1        ← 余数
模板|//
模板|// ⚠⚠⚠ **这一课唯一要记住的坑：整数除法会丢掉小数。**
模板|//
模板|//     17 / 5   ⇒  3        （不是 3.4！）
模板|//     1 / 2    ⇒  0        （不是 0.5！）
模板|//
模板|// 为什么：两边都是 int，C 就用整数运算，小数部分**直接扔掉**（不是四舍五入）。
模板|// 而且它**不报错、不警告** —— 你只会拿到一个错的结果。这是最难查的一类 bug。
模板|//
模板|// 想要小数，必须让**至少一边是小数**：
模板|//     17.0 / 5     ⇒  3.4
模板|//     17 / 5.0     ⇒  3.4
模板|//     (double)17 / 5  ⇒  3.4        ← 强制转换，第 04 课细讲
模板|//
模板|// `%` 取余很有用：判断能不能整除（`x % 2 == 0` 就是偶数）。
模板|//
模板|// ─────────────────────────────────────────────────────
模板|//  用法与例子
模板|// ─────────────────────────────────────────────────────
模板|//
模板|//  ① 直接算并打印（最简单的形式）：
模板|//
模板|//      printf("%d\n", 3 + 2);              ⇒ 5
模板|//
模板|//  ② 用变量算 —— 这是你以后真正会写的样子：
模板|//
模板|//      int 甲 = 17;
模板|//      int 乙 = 5;
模板|//      printf("%d\n", 甲 / 乙);            ⇒ 3
模板|//      printf("%d\n", 甲 % 乙);            ⇒ 2
模板|//
模板|//  ③ 优先级和数学一样：先乘除取余，后加减；想先算就加括号。
模板|//

模板|//     double   双精度    大约 15 位      ← **默认选它**

模板|//

模板|//
模板|// ⚠⚠⚠ **这一课唯一要记住的坑：scanf 必须写 `&`。**
模板|//
模板|//     为什么：printf 是"把值给出去"，只要值就行；
模板|//     而 scanf 是"把读到的值**存进去**"，它必须知道**存到哪块内存**。

模板|//
模板|//     写了 &  ⇒  正确
模板|//     忘了 &  ⇒  程序**可能在运行时崩溃**（Segmentation fault），
模板|//                也可能"看起来跑完了"但变量没被赋值 ——
模板|//                编译器只给个警告，不报错。所以特别危险。
模板|//
模板|// ⚠ 格式符要和类型对上：
模板|//     读 int      scanf("%d", &x);
模板|//     读 double   scanf("%lf", &x);     ← ⚠ 是 %lf（有个 l），不是 %f
模板|//     读字符      scanf("%c", &c);
模板|//
模板|// ─────────────────────────────────────────────────────
模板|//  用法与例子
模板|// ─────────────────────────────────────────────────────
模板|//
模板|//  ① 读一个整数：
模板|//
模板|//      int 数;
模板|//      scanf("%d", &数);              程序会在这里**停下来等你敲**
模板|//
模板|//  ② 读进来就能用 —— 和普通变量没有区别：
模板|//
模板|//      printf("%d\n", 数 + 1);
模板|//
模板|//  ③ 一次读两个值：两个占位符，两个地址，敲的时候用空格或回车隔开。
模板|//
模板|//      int 甲, 乙;
模板|//      scanf("%d %d", &甲, &乙);      输入 "3 5" ⇒ 甲=3 乙=5
模板|//
模板|//  ④ ⚠ 读 double 和读 int 的格式符**不一样**，这是最容易记错的一处：
模板|//
模板|//      int x;      scanf("%d",  &x);      /* 读整数 */
模板|//      double y;   scanf("%lf", &y);      /* ⚠ 读小数要写 %lf */
模板|//
模板|//  一个完整的、能跑的例子：
模板|//
模板|//      #include <stdio.h>
模板|//
模板|//      int main(void) {
模板|//          int 数;
模板|//          scanf("%d", &数);           /* ⚠ 这个 & 是这一课的全部重点 */
模板|//          printf("%d\n", 数 + 1);
模板|//          return 0;
模板|//      }
模板|//
模板|//  运行（假设你敲了 5）：
模板|//

模板|//      6                               ← 程序打印的
模板|//
模板|//  ⚠ 界面上的「检查」会**替你敲**一个数进去，你不用手动输入。
模板|//    但它敲几次、敲什么值，取决于这一课的检查项 ——
模板|//    所以别写死任何前提（比如"假设用户一定输入正数"）。
模板|//
模板|// ─────────────────────────────────────────────────────

标题|第 11 课：指针 —— 改参数，外面会不会变
要求|写函数 void 加倍(int *p)：把 p 指向的那个数乘以 2
模板|// 第 11 课：指针 —— 改参数，外面会不会变
模板|//
模板|// ─────────────────────────────────────────────────────
模板|//  先介绍：为什么需要指针
模板|// ─────────────────────────────────────────────────────
模板|//
模板|// 先看一个"不生效"的函数：
模板|//
模板|//     void 加倍(int x) {
模板|//         x = x * 2;            ← 改的是**拷贝**
模板|//     }
模板|//
模板|//     int 数 = 5;
模板|//     加倍(数);
模板|//     printf("%d\n", 数);       ⇒ 还是 5！
模板|//
模板|// 为什么：C 的函数参数默认是**按值传递** —— 传进去的是一份**拷贝**。
模板|// 函数里怎么改，都动不到外面那个变量。
模板|//
模板|// 想改到外面，就要传**地址**：
模板|//
模板|//     void 加倍(int *p) {       ← p 是"指向一个 int 的指针"
模板|//         *p = *p * 2;          ← *p 是"p 指向的那个数"
模板|//     }
模板|//
模板|//     int 数 = 5;
模板|//     加倍(&数);                ← 传地址（那个 & 又出现了）
模板|//     printf("%d\n", 数);       ⇒ 10  ✅
模板|//
模板|// ⚠⚠ 两个符号别搞混 —— 这是这一课唯一要记住的东西：
模板|//
模板|//     &数     取地址 —— "数在内存的哪里"
模板|//     *p     取值   —— "p 指的那个地方**里面**是什么"
模板|//
模板|//   在**声明**里 `int *p` 的 `*` 是"这是个指针"；
模板|//   在**表达式**里 `*p` 的 `*` 是"取出它指的东西"。同一个符号两种意思。
模板|//
模板|// ⚠ 第 05 课的 `scanf("%d", &数)` 就是这个道理 ——
模板|//   它要改你那个变量，所以必须知道地址。
模板|//
模板|// ─────────────────────────────────────────────────────
模板|//  用法与例子
模板|// ─────────────────────────────────────────────────────
模板|//
模板|//  ① 先亲眼确认"按值传递改不到外面"（这段值得你跑一遍）：
模板|//
模板|//      #include <stdio.h>
模板|//
模板|//      void 加倍(int x) { x = x * 2; }        /* 改的是拷贝 */
模板|//
模板|//      int main(void) {
模板|//          int 数 = 5;
模板|//          加倍(数);
模板|//          printf("%d\n", 数);                ⇒ 5   ← 没变！
模板|//          return 0;
模板|//      }
模板|//
模板|//  ② 换成指针，就改到了：
模板|//
模板|//      void 加倍(int *p) { *p = *p * 2; }

模板|//      int main(void) {
模板|//          int 数 = 5;

模板|//          return 0;

模板|//
模板|//      int 数 = 5;

模板|// ─────────────────────────────────────────────────────
模板|//

模板|// 直接写 `3.14159` 散落在各处，改的时候要找遍全文 —— 而且容易漏。
模板|//

模板|//
模板|//   ① **#define**（预处理宏）—— 老办法，用得最广
模板|//

模板|//     #define 圆周率 3.14159        ✅
模板|//
模板|//   为什么：`#define` 是**纯粹的文本替换**，不是变量声明。
模板|//   编译器在编译前，把所有 `圆周率` 三个字**原样换成** `3.14159`。
模板|//   所以那个分号会一起被换进去，变成 `printf("%f", 3.14159;);` ⇒ 语法错。
模板|//

模板|// 第 15 课：指针与数组 —— 数组名是什么
模板|//
模板|// ─────────────────────────────────────────────────────
模板|//  先介绍：数组名其实是一个地址
模板|// ─────────────────────────────────────────────────────
模板|//
模板|//     int 数们[3] = {1, 2, 3};
模板|//
模板|// `数们` 这个名字，作为表达式的值，等于 **&数们[0]**（第一个元素的地址）。
模板|// 所以下面两种写法**完全等价**：
模板|//
模板|//     数们[i]
模板|//     *(数们 + i)
模板|//
模板|// 搞懂这一点，就明白了三件事：
模板|//
模板|//   ① 为什么数组作为参数传给函数时**会丢掉长度** ——
模板|//      因为传进去的只是"第一个元素的地址"，末尾没有"到此为止"的信息。
模板|//      ⇒ 所以第 09 课那个函数要另外传 `个数`。
模板|//
模板|//   ② 为什么函数里**能改到原数组** ——
模板|//      因为它拿到的是地址，`数们[i] = x` 写的就是原来那块内存。
模板|//      （对比第 11 课：普通 int 参数改不到外面，数组能改到 —— 就在这里。）
模板|//
模板|//   ③ 为什么 `数们[i]` 和 `*(数们 + i)` 一样：
模板|//      `数们 + i` 是"往后数 i 个格子"的地址，`*` 再把里面的值取出来。
模板|//
模板|// ⚠ 参数写成 `int *数们` 或 `int 数们[]` **完全一样** ——
模板|//   编译器把它们当同一件事。看到两种写法都别慌。
模板|//
模板|// ─────────────────────────────────────────────────────
模板|//  用法与例子
模板|// ─────────────────────────────────────────────────────
模板|//
模板|//  ① 两种下标写法，结果一模一样：
模板|//
模板|//      int 数们[3] = {1, 2, 3};
模板|//      printf("%d\n", 数们[1]);            ⇒ 2
模板|//      printf("%d\n", *(数们 + 1));        ⇒ 2      ⚠ 完全等价
模板|//
模板|//  ② 指针算术是"按格子走"，不是"按字节走"：
模板|//
模板|//      数们 + 1      往后**一个 int**（4 字节），不是 1 字节
模板|//      数们 + 2      再往后一个 ⇒ 指向 数们[2]
模板|//
模板|//      ⚠ 编译器知道 `数们` 指向的是 int，所以它自动乘上 sizeof(int)。
模板|//        这就是为什么"指针要分类型"。
模板|//
模板|//  ③ 参数两种写法等价，随你选：
模板|//
模板|//      void 全部加一(int *数们, int 个数) { ... }
模板|//      void 全部加一(int 数们[], int 个数) { ... }      /* 同一件事 */
模板|//
模板|//  ④ **能改到原数组** —— 这是这一课要你亲手验证的事：
模板|//
模板|//      void 全部加一(int *数们, int 个数) {
模板|//          for (int i = 0; i < 个数; i++) {
模板|//              数们[i] += 1;               /* 改的是原数组 */
模板|//          }
模板|//      }
模板|//
模板|//  一个完整的、能跑的例子：
模板|//
模板|//      #include <stdio.h>
模板|//
模板|//      void 全部加一(int *数们, int 个数) {
模板|//          for (int i = 0; i < 个数; i++) {
模板|//              数们[i] += 1;
模板|//          }
模板|//      }
模板|//
模板|//      int main(void) {
模板|//          int 数据[] = {1, 2, 3};
模板|//          全部加一(数据, 3);

模板|//          }
模板|//          return 0;

模板|//

模板|// ─────────────────────────────────────────────────────
模板|//  常见坑
模板|// ─────────────────────────────────────────────────────
模板|//
模板|//  ⚠ 坑 1：以为 `数们 + 1` 是"地址加 1 个字节"
模板|//
模板|//      错误想法：
模板|//          int 数们[3] = {1, 2, 3};
模板|//          printf("%d\n", *(数们 + 1));        /* 有人以为是"第二个字节" */

模板|//      你会看到什么：

模板|//

答案|void 统计(int 数们[], int 个数, int *最大, int *最小) {
答案|    /* ⚠ 空数组要特判，否则 数们[0] 就越界读了 */
答案|    if (个数 <= 0) {
答案|        return;
答案|    }
答案|    /* ⚠ 初值从第一个元素起 —— 写 0 的话全负数就错了 */
答案|    int 大 = 数们[0];
答案|    int 小 = 数们[0];
答案|    for (int i = 1; i < 个数; i++) {
答案|        if (数们[i] > 大) 大 = 数们[i];
答案|        if (数们[i] < 小) 小 = 数们[i];
答案|    }
答案|    *最大 = 大;              /* ⚠ *最大 才是"写进调用者的变量" */
答案|    *最小 = 小;
答案|}
