  OK  因数个数：1、2、12、36、100 都要对（36 是完全平方数）
  OK  ★ 是质数：小数字 + 接近 10^9 的大质数（试到 n 会超时）
  OK  质因数个数：按重数算
  OK  最大质因数：含「剩下一个大质数」的情况
  XX  ★ 是质数不许一个个试到 n（试到 √n 就够）
        「是质数」里的循环是**试到 n 为止**的：
              for (int i = 2; i < n; i++) { if (n % i == 0) { return false; } }
              这一课最该记住的一句话：**试到 √n 就够了**。
              为什么：如果 n 有个因数 d 大于 √n，那 n/d 一定**小于** √n，
                而 n/d 也是 n 的因数 —— 它在前面那一趟里已经被试过了。
                ⇒ 大于 √n 的因数不可能单独出现，不用试。
              本机实测（判 999999937 这个大质数）：
                  试到 √n        0 毫秒
                  试到 n         2527 毫秒        ← 慢了几万倍
              改成：
                  for (int i = 2; (long long)i * i <= n; i++)
              ⚠ 别用 sqrt(n) —— 它返回浮点数，大数时会算不准；
                `i * i <= n` 全程整数，不会错（记得转 long long，免得 i*i 溢出）。
