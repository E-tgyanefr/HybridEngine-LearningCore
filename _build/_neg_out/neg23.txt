  XX  ★ 不许用 std::gcd / __gcd，要自己写辗转相除
        源码里用到了现成的：std::gcd
              它们的答案当然对，但这一课要你亲手写出那两行：
                  if (b == 0) { return a; }
                  return 最大公约数(b, a % b);
              为什么值得手写：
                · 这是「为什么能换小」的最好练习 —— {a,b} 和 {b,a%b} 的公约数集合完全相同；
                · `std::gcd` 是 C++17 才有的，很多考场环境不给；
                · 扩展欧几里得、中国剩余定理都是从这两行长出来的。
  XX  ★ 最大公约数里要用到 %（辗转相除的本质是取余）
        「最大公约数」的函数体里没有见到 `%`。
              辗转相除的本质就是「大数换小数、小数换余数」，没有取余就不是它了：
                  while (b != 0) { long long 余 = a % b; a = b; b = 余; }
                  return a;
              或者递归写法：
                  if (b == 0) { return a; }
                  return 最大公约数(b, a % b);
              如果写的是「从 1 试到小的那个」那种笨办法，也能过用例，
              但数字一大（10^9）就慢得没法用了 —— 那不是这一课要教的。
