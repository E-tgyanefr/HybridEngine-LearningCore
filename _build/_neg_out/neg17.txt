  XX  ★ 三个函数体里各自都要有你自己写的循环
        检查了去掉注释后的源码，发现问题：
              冒泡排序：这个函数体里一个循环都没有
              选择排序：这个函数体里一个循环都没有
              插入排序：这个函数体里一个循环都没有
              排序的本质是「反复比较、反复交换」，所以一定有一层或两层循环：
                  冒泡  for (i…) for (j…) if (数[j] > 数[j+1]) 交换
                  选择  for (i…) { for (j…) 找最小; 交换 }
                  插入  for (i…) { while (j >= 0 && 数[j] > 拿着) 右挪 }
              如果输出是几个赋值语句拼出来的，数字碰巧对也不算学会 ——
              检查里换一组数据（含重复元素的那组）立刻就错了。
