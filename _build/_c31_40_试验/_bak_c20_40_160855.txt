模板|//

模板|// 三种写法，干的是同一件事，思路完全不同：
模板|//
模板|//   冒泡：邻居两个两个比，大的往后挪 —— 像气泡往上冒
模板|//   插入：像理扑克牌，把新摸到的牌插进已经排好的那一段
模板|//   选择：每一轮从剩下的里挑出最小的，放到前面
模板|//
模板|// ─────────────────────────────────────────────────────
模板|//  一、三种排序共同的骨架
模板|// ─────────────────────────────────────────────────────
模板|//
模板|//     for (int i = 0; i < n - 1; i++) {        外层：一共几轮
模板|//         for (int j = ...; j < ...; j++) {    内层：这一轮比哪些
模板|//             ...
模板|//         }
模板|//     }
模板|//
模板|// ⚠ 外层只走到 n - 1：最后一轮只剩一个元素，它本来就该在那儿。
模板|//
模板|// ─────────────────────────────────────────────────────
模板|//  二、交换：三句话，一句都不能少
模板|// ─────────────────────────────────────────────────────
模板|//
模板|//     int t = a[j];         ← 先存起来
模板|//     a[j] = a[j + 1];      ← 覆盖
模板|//     a[j + 1] = t;         ← 把存的放回去
模板|//
模板|// ⚠ 要交换两个格子，**必须有第三个变量**。少了 t 就变成覆盖（见下面的坑）。
模板|//
模板|// ─────────────────────────────────────────────────────
模板|//  三、冒泡
模板|// ─────────────────────────────────────────────────────
模板|//
模板|//     for (int i = 0; i < n - 1; i++) {
模板|//         for (int j = 0; j < n - 1 - i; j++) {
模板|//             if (a[j] > a[j + 1]) { 把这两个换过来 }
模板|//         }
模板|//     }
模板|//
模板|// ⚠ 内层上界写 **n - 1 - i**，不是 n - 1，更不能写 n：
模板|//     n - 1 - i ：每走完一轮，末尾就多一个排好的，不用再比（最省）
模板|//     n - 1     ：结果一样，只是白比几轮
模板|//     n         ：会读到 a[n] —— **越界**，那是别人家的内存
模板|//
模板|// ─────────────────────────────────────────────────────
模板|//  四、插入
模板|// ─────────────────────────────────────────────────────
模板|//
模板|//     for (int i = 1; i < n; i++) {

模板|//         int j = i - 1;                      ← 这个位置就空出来了
模板|//         while (j >= 0 && a[j] > 手里) {
模板|//             a[j + 1] = a[j];                ← 比手里大的往后挪一格
模板|//             j--;
模板|//         }
模板|//         a[j + 1] = 手里;                    ← 找到位置，放回去
模板|//     }
模板|//
模板|// ⚠ 两处最容易写错：
模板|//   ① `j >= 0` 必须写在 `&&` **前面**。反过来的话 j 会减到 -1 再去读 a[-1]。
模板|//   ② 最后放回的位置是 **j + 1**，不是 j（循环退出时 j 已经又减了一次）。

模板|//  五、选择

模板|// ⚠ 记的是**下标**，不是值。记值的话你只知道"最小是 1"，

模板|//
模板|// ─────────────────────────────────────────────────────

模板|// ─────────────────────────────────────────────────────

模板|// 第 19 课写过这个斐波那契：
模板|//
模板|//     int 斐波那契(int n) {
模板|//         if (n <= 1) return n;
模板|//         return 斐波那契(n - 1) + 斐波那契(n - 2);     ← 算 fib(45) 要等很久
模板|//     }
模板|//
模板|// 慢的原因第 19 课说过：**同一个答案被重复算了无数遍**。
模板|//
模板|// 换个方向想：既然要算到 fib(45)，那就**从 fib(0) 开始一个一个往上算**，
模板|// 每算出一个就记在表里 —— 每个答案只算一次，一次也不浪费：
模板|//
模板|//     表[0] = 0

模板|//
模板|// ─────────────────────────────────────────────────────
模板|//  一、递推的两个零件
模板|// ─────────────────────────────────────────────────────
模板|//
模板|// ① **初始值** —— 表里最小的那几项，手写死
模板|// ② **递推式** —— 表[i] 怎么由前面几项算出来
模板|//
模板|//     int 表[50];
模板|//     表[0] = 0;                          ← ① 初始值
模板|//     表[1] = 1;                          ← ① 初始值
模板|//     for (int i = 2; i <= n; i++) {
模板|//         表[i] = 表[i - 1] + 表[i - 2];  ← ② 递推式
模板|//     }
模板|//     return 表[n];
模板|//
模板|// ⚠ 初始值写错，后面**全错** —— 而且错得很像"对的"。这是本课的坑。

模板|// ─────────────────────────────────────────────────────

模板|//   走到第 2 级：2 种（1+1、2）
模板|//   走到第 3 级：3 种（1+1+1、1+2、2+1）
模板|//

模板|// 你可以把它想成"一根通向那个文件的管子"：
模板|//
模板|//     FILE *文件 = fopen("out.txt", "w");     ← 打开管子

模板|// ─────────────────────────────────────────────────────

模板|// ─────────────────────────────────────────────────────

模板|//  FILE *fopen(名字, 模式)       打开文件，返回"管子"；**失败返回 NULL**
