// 第 04 课：循环 —— 让程序重复做事，并且重复得**正好**
//
// ─────────────────────────────────────────────────────
//  先介绍：循环是"程序能干活"的开始
// ─────────────────────────────────────────────────────
//
// 求和、计数、查找、遍历 —— 这些活全都是"把同一件事做很多遍"。
// 没有循环，你只能把一行代码抄十遍，改一个地方要改十处。
//
// 但循环有一类和前面完全不同的错法：**它不报错、也不崩**，只是把结果算错
// 一点点，而那一点点很难看出来：
//
//     差一错误（off-by-one）：for (int i = 1; i < n; i++) 少跑一次。
//       算 1..10 的和，它给你 45 —— 看上去像个正常答案。
//     写反方向的差一：for (int i = 0; i <= 次数; i++) 多跑一次，
//       重复 3 遍变成 4 遍 —— 同样一声不吭。
//
// 所以这一课真正的功夫不在"会写循环"，而在**数清楚它跑几遍**。
//
// 还有一个**好消息**：Java 里"累加变量没给初值"是**编译错误**，不是"碰巧算对"。
//       C++：int 和; 里面是内存里的残留值，程序照跑，可能碰巧算出"正确答案"；
//       Java：直接报「可能尚未初始化变量和」，程序根本编译不出来。
//   Java 用一条编译错误，把这类"结果时对时错"的 bug 从你身上拿走了。
//
// ─────────────────────────────────────────────────────
//  用法与例子
// ─────────────────────────────────────────────────────
//
// ① for：**次数已知**的时候用它（最常用）
//
//     for (int i = 1; i <= n; i++) { 和 += i; }     ← 从 1 数到 n（含 n）
//     for (int i = 0; i < n; i++) { 结果 += 文字; }  ← 从 0 数起，一共 n 个
//
//   三个部分读作：**开始**（i = 1）；**继续的条件**（i <= n）；**每次做完
//   干什么**（i++ 就是 i = i + 1）。
//
//   ⚠ 这两种写法都对，但**别混**：
//       从 1 数到 n（含 n）  →  条件写 <= n
//       从 0 数起、一共 n 个  →  条件写 < n
//
// ② while：**以条件为主**，不知道要跑几次
//
//     int 试 = 2;
//     while (试 < n) {
//         if (n % 试 == 0) { ... }
//         试++;
//     }
//
//   先看条件，为真才进。**可能一次都不跑。**
//
// ③ do-while：**至少执行一次**（先做一遍，再看条件）
//
//     do {
//         位++;
//         剩 /= 10;
//     } while (剩 > 0);
//
//   ⚠ 注意结尾那个**分号**，是 do-while 独有的。什么时候非它不可：数位数。
//     n = 0 也是 1 位数，可 while (剩 > 0) 在 n = 0 时一次都不跑，会给出 0 位。
//
// ④ 增强 for：把数组/集合里的元素一个一个拿出来
//
//     for (int x : 数字) { ... }         ← 读作"对于 数字 里的每一个 x"
//
// ⑤ break 和 continue：两个方向的中断
//
//     break      立刻跳出**整个**循环（后面的轮次都不跑了）
//     continue   跳过**这一轮**剩下的部分，直接进入下一轮
//
//   ⚠ 用 continue 时最容易踩的坑：忘了让循环变量往前走 → 死循环（见坑 3）。
//
// ⑥ 累加变量必须给初值：int 和 = 0;（累加用 0）   int 积 = 1;（累乘用 1）
//
// ─────────────────────────────────────────────────────
//  常见坑
// ─────────────────────────────────────────────────────
//
// ⚠ 坑 1：差一错误（off-by-one）—— 少跑一次 / 多跑一次
//
//     for (int i = 1; i < n; i++) 和 += i;         ← 少跑一次（最后一个没加）
//     for (int i = 0; i <= 次数; i++) 结果 += 文字;  ← 多跑一次
//
// 你会看到：**什么都不报**。
//   求和(1) 会给出 0（正确答案是 1）；重复("*", 1) 会给出 "[**]"（应该是 "[*]"）。
// 为什么：循环跑几次只由条件决定，编译器不知道"你心里想跑几次"。
// ⇒ **写完循环，一定拿 n = 0 和 n = 1 各在心里走一遍**：n = 0 时该不该跑？
//   n = 1 时该跑几次？这两问答对了，差一错误就躲开了。
//   本课有一条检查专门盯这里，而且它会告诉你**是哪一种**：是"少跑了最后一次"，
//   还是"多跑了一轮"。
//
// ⚠ 坑 2：累加变量没给初值
//
//     int 和;
//     for (int i = 1; i <= n; i++) 和 += i;
//
// 你会看到：错误: 可能尚未初始化变量和
// 为什么：**局部变量必须先赋初值才能用**，Java 会一条一条路径地检查。
//   ✅ 这里必须说一句：**这是 Java 的优点，不是刁难** —— 同样的写法在 C++ 里
//     能编译能运行，因为未初始化的局部变量装的是内存里的残留值：这次碰巧是 0，
//     你的累加就"算对了"，换个编译器、换个运行顺序它又变成别的数 —— 那是最
//     难查的一类 bug。Java 直接不让你编译，等于把这类 bug 拿走了。
// ⇒ 声明的时候就写清楚：int 和 = 0;   int 积 = 1;
//
// ⚠ 坑 3：用 continue 时忘了让循环变量往前走 —— 死循环
//
//     int i = 0;
//     while (i < 10) {
//         if (i % 2 == 0) { continue; }      ← 跳过了下面的 i++，i 永远不变
//         i++;
//     }
//
// 你会看到：程序**一直不结束**（界面上的检查会卡到超时）。不是崩溃，不是报错，
//   就是没完没了。
// 为什么：continue 跳到"下一轮"，而 while 的下一轮又是从同一个条件开始 ——
//   i 一直没变，条件永远为真。
// ⇒ 用 while + continue 时，把"往前走"那一步放在 continue **之前**，或者干脆
//   用 for（for 的 i++ 写在头部，continue 跳不过它）。
//
// ⚠ 坑 4：在 for 的括号里声明的变量，出了循环就没了
//
//     for (int i = 0; i < 3; i++) { ... }
//     System.out.println(i);          ← 这里用不了 i
//
// 你会看到：错误: 找不到符号   符号: 变量 i   位置: 类 Main
// 为什么：`for (int i = ...)` 里的 i 是**这个循环专有的**，它的活动范围就是
//   循环那一对花括号。出去就不认识了。
// ⇒ 要在循环外用到这个数，就把它声明在外面：
//       int i = 0;   for (i = 0; i < 3; i++) { ... }
//
// ─────────────────────────────────────────────────────
//  轮到你了 —— 在下面写
// ─────────────────────────────────────────────────────
//
// ⚠ 写五个**方法**（不用写 main、不用写 class、不用写 import ——
//   检查时会自动套进 class Main 里调用）。五个都要写 static。
//
//   1. static int 求和(int n)                ← 用 **for**
//        1 + 2 + ... + n；n <= 0 时返回 0
//
//   2. static String 重复(String 文字, int 次数)   ← 用 **for**
//        例如 重复("*", 3) 得到 "***"
//        次数 <= 0 时返回**空字符串** ""（不是 null，也不是 "null"）
//
//   3. static int 数位数(int n)              ← 必须用 **do-while**
//        n 有几位数字：0 → 1   7 → 1   10 → 2   12345 → 5（n 保证 >= 0）
//      ⚠ 0 也要数出 1 位 —— 想想为什么这一题**非 do-while 不可**：
//        while (剩 > 0) 这种写法在 n = 0 时一次都不跑，会给出 0 位。
//
//   4. static int 最小因数(int n)             ← 用 **while**，找到后用 **break** 跳出
//        n 的最小因数（能整除 n、并且 >= 2 的最小的数）
//          9 → 3      10 → 2      4 → 2      49 → 7
//        n < 2 时返回 -1；找不到因数（n 是质数）就返回 n 本身：7 → 7
//
//   5. static int 偶数个数(int[] 数字)        ← 用**增强 for**，用 **continue** 跳过奇数
//        偶数个数(new int[]{1, 2, 3, 4}) → 2；空数组 → 0
//
// 三种循环的分工：for 次数已知（最常用）；while 以条件为主；do-while **至少
//   执行一次**；for (int x : 数组) 增强 for。
//
// 写的时候顺手自检：求和(1) 是 1 吗？重复("*", 1) 是 "[*]" 吗？数位数(0) 是 1 吗？
//
