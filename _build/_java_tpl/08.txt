// 第 08 课：类与对象 —— 自己造一种"东西"
//
// ─────────────────────────────────────────────────────
//  先介绍：为什么需要"自己造一种类型"
// ─────────────────────────────────────────────────────
//
// 前面七课用的都是 Java 自带的东西：int、String、ArrayList。
// 可现实里的东西，Java 一个都没带：
//
//     一只猫    有名字、有年龄，会打招呼、会长大
//     一个学生  有姓名、有分数，会自我介绍
//
// 用一个 int 装年龄、一个 String 装名字，它们**其实是同一条数据的两半** ——
// 可编译器不知道这件事，你也没法把它们一起传来传去、一起返回。
//
// `class` 就是干这个的：**把"有什么"（字段）和"能做什么"（方法）
// 捆成一个新的类型**。从此 `猫` 就和 `int` 一样是个类型了：
//
//     class 猫 {
//         String 名字;         ← 字段：这只猫"有什么"
//         int 年龄;
//         String 打招呼() {    ← 方法：这只猫"能做什么"
//             return "喵～我是" + 名字;
//         }
//     }
//
// ⚠ 一定要分清这两个词，它们是这一课的骨架：
//
//     class 猫 { ... }               ← **图纸**：说清"猫有什么、能做什么"
//     猫 甲 = new 猫("咪咪", 3);      ← 照着图纸**造一只真的猫**
//
//   图纸只有一份，猫可以造很多只 —— 而且每一只**各有各的名字和年龄**。
//
// ─────────────────────────────────────────────────────
//  用法与例子
// ─────────────────────────────────────────────────────
//
// ① 三个部件：字段、构造方法、普通方法
//
//     class 猫 {
//         String 名字;                       ← 字段（每个对象各有一份）
//         int 年龄;
//
//         猫(String 名字, int 年龄) {         ← 构造方法（没有返回类型！）
//             this.名字 = 名字;
//             this.年龄 = 年龄;
//         }
//
//         String 打招呼() {                  ← 普通方法
//             return "喵～我是" + 名字;
//         }
//     }
//
// ② new 的时候发生了什么
//
//     猫 甲 = new 猫("咪咪", 3);
//
//   读作：照着 猫 这张图纸要一块新地方 → 把 "咪咪" 和 3 交给构造方法 →
//   构造方法把两个值填进字段 → 把这只猫的地址交给变量 甲。
//   你**从来不直接"调用"构造方法** —— 它是 new 的那一刻自动执行的。
//
// ③ 用 `.` 访问对象自己的东西
//
//     甲.打招呼() ⇒ 喵～我是咪咪      甲.几岁了() ⇒ 3      甲.长大一岁();
//
// ④ this 的意思是"我自己这个对象"
//
//   字段名和参数名一样时（都叫 名字），右边的 名字 指**参数**，
//   要写 this.名字 才指得到**字段**：
//
//       猫(String 名字, int 年龄) {
//           this.名字 = 名字;        ← this.名字 是字段；右边的 名字 是参数
//           this.年龄 = 年龄;
//       }
//
//   忘了 this、写成 名字 = 名字; 是把参数赋给自己 —— 字段永远是 null / 0。
//
// ⑤ new 两次就是两个互不相干的对象
//
//     猫 甲 = new 猫("咪咪", 3);
//     猫 乙 = new 猫("大黄", 5);
//     甲.长大一岁();
//     甲.几岁了() ⇒ 4   ← 甲变了        乙.几岁了() ⇒ 5   ← 乙一点没受影响
//
// ⑥ 但 `猫 乙 = 甲;` **不是**拷贝
//
//     猫 乙 = 甲;                ← 不是拷贝！只是给同一只猫起了第二个名字
//     乙.长大一岁();
//     甲.几岁了() ⇒ 4            ← 甲也变了，因为它们**是同一只猫**
//
//   Java 的类类型变量里装的不是对象本身，而是"对象在哪里"（引用/地址）。
//   `猫 乙 = 甲;` 只是把地址抄了一份。想造真正的第二只，得再 new 一次。
//   ⚠ 这一点和 C++ 的值语义**相反** —— 那边 猫 乙 = 甲; 会复制一份。
//
// ⑦ 这一课不用你写 Main
//
//   课程会在你的类后面补一个 public class Main 当入口，所以你只写 `class 猫`
//   就行。**别自己写 class Main** —— 一个 .java 文件里 public 类只能有一个，
//   那个位置留给课程了。
//
// ─────────────────────────────────────────────────────
//  常见坑
// ─────────────────────────────────────────────────────
//
// ⚠ 坑 1：给构造方法写了返回类型（本课最隐蔽的坑）
//
//     class 猫 {
//         void 猫(String 名字, int 年龄) { ... }      ← 多了个 void
//     }
//
// 你会看到的是**在 new 的那一行**：
//     错误: 无法将类 猫中的构造器 猫应用到给定类型
//        需要: 没有参数
//        找到: String,int
//        原因: 实际参数列表和形式参数列表长度不同
//   ⚠ 报错里**根本看不到 void 两个字** —— 这就是它难查的原因。
// 为什么：构造方法的两条硬规矩是 ① 名字必须和类名**完全一样**（大小写也一样）；
//   ② **没有返回类型** —— 连 void 都不能写。写上 void 之后，`void 猫(...)`
//   就只是一个**名字碰巧和类名一样的普通方法**，编译器不觉得这是语法错误。
//   于是 猫 这个类实际上**没有任何构造方法**，new 猫("咪咪", 3) 自然对不上
//   （编译器只认那个默认的无参构造）。
// ⇒ 把返回类型删掉（前面最多只能写 public / private 这种访问修饰符）：
//       猫(String 名字, int 年龄) {        ✓ 这才是构造方法
//           this.名字 = 名字;
//           this.年龄 = 年龄;
//       }
//
// ⚠ 坑 2：构造方法里忘了 this
//
//     猫(String 名字, int 年龄) {
//         名字 = 名字;           ← 把参数赋给了自己
//         年龄 = 年龄;
//     }
//
// 你会看到：什么都不报。只是 new 出来的猫**名字是 null、年龄是 0**：
//     甲.打招呼() ⇒ 喵～我是null        甲.几岁了() ⇒ 0
// 为什么：字段名和参数名一样时，**右边的 名字 指参数**。所以 `名字 = 名字;`
//   是把参数赋值给它自己，字段一点没动。
// ⇒ 用 this 指名道姓：this.名字 = 名字;   this.年龄 = 年龄;
//   ⚠ 顺便记住 Java 的默认值：字段不赋值不是"空着"，而是各自类型的零值 ——
//     对象类型（String）是 **null**，int 是 **0**，boolean 是 **false**。
//
// ⚠ 坑 3：给字段加了 static —— 所有对象共用一份
//
//     class 猫 {
//         static int 年龄;          ← 这一份属于**类**，不属于某只猫
//     }
//
// 你会看到：什么都不报。只是造两只猫、改其中一只，**两只一起变**：
//     甲 = new 猫(3);  乙 = new 猫(5);   甲.年龄 = 甲.年龄 + 1;
//     甲.年龄 ⇒ 6        乙.年龄 ⇒ 6      ← 乙明明没动过，却跟着变了
// 为什么：**static 的东西属于"类"，只存一份；不写 static 的属于"对象"，
//   每个对象各一份。**
// ⇒ 这一课要的正是"每个对象各有一份"，所以字段和方法都**不要写 static**。
//   （第 05 课里的 static 是另一种用法：那是"和对象无关的纯计算"。）
//
// ⚠ 坑 4：给自己的类写了 public
//
//     public class 猫 { ... }              ← 多了 public
//
// 你会看到：错误: 类 猫 是公共的, 应在名为 猫.java 的文件中声明
// 为什么：**一个 .java 文件里只能有一个 public 类，而且它的名字必须和文件名
//   一样。** 这个文件叫 Main.java，那个 public 的位置留给课程的 Main 了。
// ⇒ 把 public 去掉：class 猫 { ... }
//   ⚠ 同一个文件里可以有多个类，但 public 只能有一个 —— 这是 Java 独有的规矩。
//
// ⚠ 坑 5：以为 `猫 乙 = 甲;` 是复制了一只猫
//
//     猫 甲 = new 猫("咪咪", 3);
//     猫 乙 = 甲;              ← 看上去像"复制一份"，其实不是
//     乙.长大一岁();
//     甲.几岁了() ⇒ 4          ← 甲也变了
//
// 你会看到：什么都不报，只是"改乙动了甲"。
// 为什么：Java 的类类型变量存的是**引用**（对象在哪里），不是对象本身。赋值
//   只是把地址抄了一份 —— 两个名字指向**同一只猫**。
// ⇒ 想造真正的第二只：猫 乙 = new 猫("咪咪", 3);
//   ⚠ 这也解释了一件相关的事：把对象传给方法，方法里改它的字段，调用者那边
//     **看得见**（传的是地址）。
//
// ─────────────────────────────────────────────────────
//  轮到你了 —— 在下面写
// ─────────────────────────────────────────────────────
//
// ⚠ 写一个 `class 猫`（**不用写 class Main、不用写 main** —— 课程会补上）。
//
//   1. 两个字段：String 名字、int 年龄
//   2. 构造方法 猫(String 名字, int 年龄) —— 用 this 把参数存进字段
//   3. String 打招呼()  →  返回 "喵～我是" + 名字
//   4. int 几岁了()     →  返回 年龄
//   5. void 长大一岁()  →  年龄 = 年龄 + 1
//
// 期望的表现：
//     猫 甲 = new 猫("咪咪", 3);
//     甲.打招呼() ⇒ 喵～我是咪咪        甲.几岁了() ⇒ 3
//     甲.长大一岁();
//     甲.几岁了() ⇒ 4
//
//     猫 乙 = new 猫("大黄", 7);
//     乙.打招呼() ⇒ 喵～我是大黄        ← 不是"咪咪"，每只猫说自己的名字
//     乙.几岁了() ⇒ 7                  ← 不受甲的影响
//
// ⚠ 三件要想清楚的事：
//   ① 构造方法**没有返回类型**（连 void 都不写），名字必须和类名一样；
//   ② 字段名和参数名一样，所以必须写 this.名字 = 名字;
//   ③ 字段**不要**加 static —— 每只猫要有自己的一份。
//
// ─────────────────────────────────────────────────────
//  怎么自己测
// ─────────────────────────────────────────────────────
//   点界面上的「检查」。命令行（在源码目录里）：
//
//       dotnet run --project csharp/java-lessons 检查 08
//
//   看这一课要干什么：dotnet run --project csharp/java-lessons 08
//   看答案（先自己写一遍）：dotnet run --project csharp/java-lessons 答案 08
//
//   ⚠ 检查会**真的去 new 两只猫**（一只叫咪咪、一只叫大黄），然后只让其中
//     一只长大 —— 两只一起变的话，就是字段写了 static。
//
// ── 在下面写 ──
class 猫 {
    String 名字;
    int 年龄;

    猫(String 名字, int 年龄) {
        // ← 把参数存进字段
    }

    String 打招呼() {
        return "";
    }

    int 几岁了() {
        return 0;
    }

    void 长大一岁() {
        // ← 年龄加一
    }
}
