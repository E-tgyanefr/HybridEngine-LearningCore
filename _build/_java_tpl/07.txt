// 第 07 课：字符串 —— Java 最著名的那个坑
//
// ─────────────────────────────────────────────────────
//  先介绍：最常用的东西，也最容易骗你
// ─────────────────────────────────────────────────────
//
// 字符串是用来装文字的类型，你几乎每一课都在用它。但它身上有两个
// **和别的类型完全不一样**的脾气，不知道就会吃大亏：
//
//   ① **比较内容要用 .equals()，不能用 ==。**
//      而最坑的是：用 == **有时候是对的** —— 于是你以为自己会了。
//
//          String a = "hi";
//          String b = new String("hi");
//          a == b            ⇒ false   ← 明明内容一样！
//          a.equals(b)       ⇒ true
//
//          String c = "hi";  ← 直接写出来的字面量
//          a == c            ⇒ true    ← 碰巧对，骗人的
//
//      为什么碰巧对：直接写在代码里的字面量 "hi" 会被 Java 放进一个"常量池"，
//      同一个内容共用一个对象。所以两个都是字面量时 == 恰好为真。一旦字符串
//      是 **new 出来的、拼出来的、从文件/输入读进来的**，== 立刻就变成 false。
//
//      **== 不是一直错，是"有时候碰巧对"—— 那才是最危险的。**
//
//   ② **字符串改不了（immutable）。**
//      凡是"改"字符串的方法，都是**返回一个新字符串**：
//
//          s.toUpperCase();             ✗ s 一个字没变（返回值被丢掉了）
//          s = s.toUpperCase();         ✓ 把新的接住
//
//      对照第 06 课的 ArrayList：表.add(x) 会**当场改变表本身**。两者行为
//      不一样，别把直觉带过来。
//
// ─────────────────────────────────────────────────────
//  用法与例子
// ─────────────────────────────────────────────────────
//
// ① 最常用的五个方法（**每一个都带括号**，它们是方法不是属性）
//
//     s.length()            有几个字符          "你好".length()  ⇒ 2
//     s.charAt(0)           第 0 个字符         下标从 0 开始，和数组一样
//     s.toUpperCase()       转成大写（返回**新**字符串，s 本身不变）
//     s.indexOf("na")       片段第一次出现的下标；**找不到返回 -1**
//     s.substring(0, 3)     从下标 0 到 3 **之前**（含 0 不含 3）
//
//   ⚠ 两个最容易记错的地方：
//     · **找不到是 -1，不是 0。** 在开头找到才是 0 —— 所以判断有没有要用
//       if (位置 >= 0)，别写 if (位置 == 0)。
//     · **substring 是半开区间。** substring(0, 3) 取的是下标 0、1、2
//       三个字符 —— 到 3 **之前**为止。
//
// ② 比较内容：equals
//
//     a.equals(b)        ⇒ true     ✓ 比的是**内容一不一样**
//     a == b             ⇒ false    ✗ 比的是**是不是同一个对象**
//
//   一句话记住：a == b 比"是不是同一张身份证"；
//               a.equals(b) 比"两个东西长得一不一样"。
//
//   ⚠ 小技巧：a 万一是 null，a.equals(b) 会抛 NullPointerException。老手会把
//     不可能为 null 的那边写在前面："hi".equals(a) —— 常量不可能是 null。
//   ⚠ 这个坑不只坑字符串：Integer 也一样。
//       Integer 甲 = 127, 乙 = 127;   甲 == 乙  ⇒ true
//       Integer 丙 = 128, 丁 = 128;   丙 == 丁  ⇒ false
//     （因为 -128~127 有缓存，超出范围就各自 new 一个。所以 127 对、128 错。）
//
// ③ 单引号和双引号是两种东西
//
//     'j'  一个**字符**，类型是 char          "j"  一个**字符串**，类型是 String
//
//   看着像，类型完全不同，别混。
//
// ④ 字符串可以拼接
//
//     "你好，" + 姓名  ⇒ 你好，小明          "第" + 1 + "名"  ⇒ 第1名
//
//   ⚠ 顺序有讲究（第 01 课讲过）：只要某一边是字符串，+ 就变成拼接。
//
// ⑤ 为什么"改"字符串要接住返回值
//
//     String s = "hello";
//     s.toUpperCase();              ← 什么都没发生
//     System.out.println(s);        ⇒ hello
//     s = s.toUpperCase();          ← 把新字符串接回 s
//     System.out.println(s);        ⇒ HELLO
//
// ⑥ 这一课不用写 import：String 和 char 都在 java.lang 里，自动可见。
//
// ─────────────────────────────────────────────────────
//  常见坑
// ─────────────────────────────────────────────────────
//
// ⚠ 坑 1：用 == 比字符串内容（本课第一大坑）
//
//     static boolean 内容相同(String a, String b) {
//         return a == b;                   ← 错
//     }
//
// 你会看到：**什么都不报**。而且它**时对时错**：
//     内容相同("hi", "hi")                            ⇒ true    ← 碰巧对
//     内容相同(new String("hi"), "hi")                 ⇒ false   ✗ 应该 true
//     内容相同(new String("你好"), new String("你好"))  ⇒ false   ✗ 应该 true
// 为什么：== 比的不是内容，是"**这两个变量是不是指向同一个对象**"。直接写出来
//   的字面量共用常量池里的同一个对象，所以碰巧为真；只要有一边是 new 出来的、
//   拼出来的、从输入读进来的，立刻变 false。
// ⇒ 判断内容一律用 equals：return a.equals(b);
//   ⚠ 这个坑的危险程度就在于"它有时候是对的" —— 你自己试一组字面量，会觉得
//     没问题；等到数据从别处来时才突然炸。
//   把它当成一条纪律：**看到比较字符串，就用 equals。**
//
// ⚠ 坑 2：字符串的 length 少了括号
//
//     String s = "hi";
//     System.out.println(s.length);            ← 少了两个括号
//
// 你会看到：错误: 找不到符号   符号: 变量 length   位置: 类型为String的变量 s
//   （它在找一个叫 length 的**字段**，而 String 上根本没有这个字段）
// 为什么：String 是人写出来的类，长度只能做成方法 length()。
// ⇒ 加上括号：s.length()
//   ⚠ 和第 06 课的数组**正好相反**，两个一起背：
//         int[] a;     a.length      数组：属性，**不加括号**
//         String s;    s.length()    字符串：方法，**要括号**
//   为什么会这样：数组的长度是 Java 语言**内建**的东西（不是类），而 String
//   是人写出来的类，长度只能做成方法。
//
// ⚠ 坑 3：字符串用方括号取字符
//
//     String s = "java";
//     System.out.println(s[0]);                ← 方括号只对数组有效
//
// 你会看到：错误: 需要数组, 但找到String
//   （javac 在说："我以为你要按下标取，可你给的不是一个数组。"）
// 为什么：方括号 a[i] 是**数组专用**的语法。
// ⇒ 字符串用 charAt：s.charAt(0)
//   ⚠ 不过下标都是从 0 开始数的，这一点两者一样。
//
// ⚠ 坑 4：substring 越界 —— 它不是"能给多少给多少"
//
//     static String 前三个(String s) {
//         return s.substring(0, 3);            ← s 只有 2 个字符时
//     }
//
// 你会看到：Exception in thread "main" java.lang.StringIndexOutOfBoundsException:
//               Range [0, 3) out of bounds for length 2
//   程序当场停下。
// 为什么：substring **不会**"不够就少给几个"，它会直接报错。Range [0, 3) 里的
//   方括号表示"含 0"，圆括号表示"不含 3" —— 半开区间。
// ⇒ 先看一眼长度：
//       if (s.length() < 3) { return s; }        ← 不足 3 个就原样返回
//       return s.substring(0, 3);
//
// ⚠ 坑 5：忘了接住返回值（字符串改不了）
//
//     static String 变大写(String s) {
//         s.toUpperCase();                     ← 造了个新字符串，然后扔了
//         return s;                            ← 返回的是**没变过**的原串
//     }
//
// 你会看到：什么都不报，只是返回的还是小写。
//   （更糟的一种写法是干脆忘了 return，那会报：错误: 缺少返回语句）
// 为什么：**字符串是不可变的。** toUpperCase 不会改 s，它造一个新的字符串
//   交给你。你不接住，它就没了。
// ⇒ 直接把返回值交出去：return s.toUpperCase();   或者 s = s.toUpperCase();
//   ⚠ 记住这条通用规律：**凡是"改"字符串的方法，都要接住返回值。**
//     （对照第 06 课：表.add(x) 会当场改变表本身 —— 那个不用接。）
//
// ⚠ 坑 6：char 和 String 分不清
//
//     static char 第一个(String s) {
//         return "j";                          ← 双引号是 String
//     }
//
// 你会看到：错误: 不兼容的类型: String无法转换为char
// 为什么：返回类型写的是 char（单个字符），你却交了一个 String。
// ⇒ 单个字符用**单引号**：return 'j';
//   不过这一题更稳的写法是直接返回 s.charAt(0) —— 交给编译器去认类型。
//
// ─────────────────────────────────────────────────────
//  轮到你了 —— 在下面写
// ─────────────────────────────────────────────────────
//
// ⚠ 只写**方法**：不用写 class、不用写 main、不用写 import —— 课程会替你补上。
//   六个方法都要写 static。
//
//   1. static int 长度(String s)                  返回字符个数
//   2. static char 第一个(String s)               返回第一个字符
//   3. static String 变大写(String s)             返回全大写的版本（s 本身不许改）
//   4. static int 找位置(String s, String 片段)    片段第一次出现的位置；找不到返回 -1
//   5. static String 前三个(String s)             前 3 个字符；不足 3 个就原样返回
//   6. static boolean 内容相同(String a, String b) 两个字符串的**内容**是否一样
//
// 自检几组：
//     长度("hello") 5 / 长度("") 0 / 长度("你好") 2
//     第一个("java") 'j' / 第一个("你好") '你'
//     变大写("hello") "HELLO"，而且原串一个字没变
//     找位置("banana","na") 2 / 找位置("banana","x") **-1**
//     前三个("abcdef") "abc" / 前三个("ab") "ab" / 前三个("") ""
//     内容相同("hi","hi") true / 内容相同(new String("hi"),"hi") **true**
//     内容相同("hi","HI") false / 内容相同("hi","hi ") false
//
// ⚠ 最后那个 new String(...) 是有意放的：它就是专门用来抓 == 的。
//
