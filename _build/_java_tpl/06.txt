// 第 06 课：数组与集合 —— 一次装很多东西
//
// ─────────────────────────────────────────────────────
//  先介绍：一个变量只装一个值，不够用
// ─────────────────────────────────────────────────────
//
// 前几课的方法一次只处理一个值。要装一串值呢？
//
//     int 分1 = 90;
//     int 分2 = 85;
//     int 分3 = 77;
//
// 装 50 个学生就要 50 个变量名，而且**数到第几个是哪个**全靠你自己记。
// 想遍历一遍？写不出循环来 —— 循环需要一个能变的"第几个"。
//
// Java 给两种容器，这一课两个都碰：
//
//   · 数组 int[]   —— 长度**固定**，用 a[i] 取，长度写在 a.length
//   · ArrayList    —— 长度会**长大**，用 表.get(i) 取，长度写在 表.size()
//
// ⚠ 这两个容器的**写法正好相反**，这就是本课唯一的、也是最重要的门槛：
//
//         int[] a = new int[3];
//         a.length            ← 属性：一个"东西"，**不加括号**
//
//         ArrayList<Integer> 表 = new ArrayList<>();
//         表.size()           ← 方法：一个"动作"，**要加括号**
//
//   一句话记住：**数组的 length 是"东西"，字符串和集合的 length()/size()
//   是"动作"。**
//
//   好消息是：写错了 javac **会当场报错**，不像整数除法那样静默出错。所以
//   这一课的任务不是"小心别写错"，而是"看到那句报错时知道它说的是这件事"。
//
// ─────────────────────────────────────────────────────
//  用法与例子
// ─────────────────────────────────────────────────────
//
// ① 数组：定长、按下标取
//
//     int[] 数们 = new int[3];              ← 三个格子，元素**自动全是 0**
//     int[] 分数 = {90, 85, 77};            ← 直接给值（花括号，不用 new）
//
//     分数[0] ⇒ 90     分数[1] ⇒ 85     分数[2] ⇒ 77     分数.length ⇒ 3
//     下标**从 0 开始**；⚠ 长度那里没有括号。
//
//   ⚠ 两个和 C++ 不一样的地方，务必记牢：
//     · **new int[3] 之后元素自动全是 0**（Java 会初始化）。C++ 里 new int[3]
//       读出来是随机值 —— 别把那个直觉带过来。
//     · **Java 会检查下标**：分数[3] 不是"读到隔壁的内存"，而是当场抛
//       ArrayIndexOutOfBoundsException，程序立刻停下。这是好事（错误暴露得
//       早），但你要用 .length 先把范围判断好。
//
// ② ArrayList：会长大、用方法操作
//
//     ArrayList<Integer> 表 = new ArrayList<>();
//
//     表.add(9);           ← 加到最后（**它会改变这张表本身**）
//     表.get(0)            ← 取第 0 个（从 0 开始数）
//     表.size()            ← 有几个元素（⚠ 是方法，要括号）
//
//   ⚠ 尖括号里写的是 **Integer**，不是 int。Java 的泛型只收"对象类型"，基本
//     类型要先包一层：int → Integer、double → Double、boolean → Boolean。
//     写成 ArrayList<int> 会报：错误: 意外的类型 / 需要: 引用 / 找到: int
//
// ③ 两个容器的对照表（背下来最省事）
//
//                    数组 int[]              ArrayList<Integer>
//     怎么建         new int[3] / {1,2,3}    new ArrayList<>()
//     取第 i 个      a[i]                    表.get(i)
//     有几个         a.length   （无括号）    表.size()   （有括号）
//     加一个         做不到（长度固定）        表.add(值)
//     长度会变吗     不会                    会
//
// ④ 遍历：增强 for 对两者都适用（for (int x : 数们) 和 for (int x : 表)）。
// ⑤ 本课不用你写 import：课程已经在文件最上面写好了 import java.util.ArrayList;
//   —— **自己再写一遍反而会编译不过**（见坑 4）。
//
// ─────────────────────────────────────────────────────
//  常见坑
// ─────────────────────────────────────────────────────
//
// ⚠ 坑 1：数组的 length 后面加了括号（本课第一大坑）
//
//     int[] a = {1, 2, 3};
//     System.out.println(a.length());          ← 多了两个括号
//
// 你会看到：错误: 找不到符号   符号: 方法 length()   位置: 类型为int[]的变量 a
//   （它在找一个**方法**，而数组上没有这个方法）
// 为什么：数组是 Java 语言**内建**的东西，它的长度是一个**属性**（字段），
//   不是一个方法。属性就是"一个东西"，所以没有括号。
// ⇒ 去掉括号：a.length
//   ⚠ 之所以老写错，是因为**字符串正好相反**（见坑 3）。三个一起记：
//         int[] a;      a.length       数组：**不加括号**
//         String s;     s.length()     字符串：**要括号**
//         ArrayList 表;  表.size()       集合：**要括号**
//
// ⚠ 坑 2：集合的 size 少了括号
//
//     ArrayList<Integer> 表 = new ArrayList<>();
//     System.out.println(表.size);             ← 少了两个括号
//
// 你会看到：错误: size 在 ArrayList 中是 private 访问控制
//   （这句话看着吓人，其实说的就是"你碰到了一个不该直接碰的东西"）
// 为什么：ArrayList 内部的**字段**确实叫 size，但它是 private 的；对外提供的
//   那个是**方法** size()。你光写 表.size，编译器就去找字段，一找就撞上私有的。
// ⇒ 加上括号：表.size()
//   ⚠ 另一种写法是干脆用错了名字：表.length 会报
//     错误: 找不到符号   符号: 变量 length —— ArrayList 上**根本没有 length**。
//
// ⚠ 坑 3：字符串的 length 少了括号，或者下标算错走到数组外面
//
//     String s = "hi";   System.out.println(s.length);      ← 少了两个括号
//
// 你会看到：错误: 找不到符号   符号: 变量 length   位置: 类型为String的变量 s
//   （注意和坑 1 正好对称：那次是"找不到方法"，这次是"找不到变量"）
// 为什么：String 是**人写出来的类**，长度只能做成方法 length()；而数组的长度
//   是语言内建的东西，做成了属性。**两条路不一样，所以写法不一样。**
//
//     int[] a = {1, 2, 3};   a[3]               ← 合法下标只有 0、1、2
//
// 你会看到：Exception in thread "main" java.lang.ArrayIndexOutOfBoundsException:
//               Index 3 out of bounds for length 3
//   程序当场停下，后面一行都不执行。为什么：合法的下标范围是 0 … a.length - 1。
// ⇒ 判断越界要**两头都看**：return i < 0 || i >= a.length;（漏了负数那头就错）
//   ⚠ Java 会检查下标，越界就把程序打断 —— 不像 C++ 那样"悄悄"读到隔壁的内存。
//
// ─────────────────────────────────────────────────────
//  轮到你了 —— 在下面写
// ─────────────────────────────────────────────────────
//
// ⚠ 只写**方法**：不用写 class、不用写 main，**也不用写 import** ——
//   课程已经替你写好了 import java.util.ArrayList;。七个方法都要写 static。
//
//   1. static int 数组长度(int[] a)                  返回数组的长度
//   2. static int 取元素(int[] a, int i)              返回第 i 个元素（i 保证合法）
//   3. static boolean 越界了吗(int[] a, int i)        下标 i 超出范围就返回 true
//   4. static int[] 新建数组(int n)                   返回一个长度为 n 的新数组
//   5. static int 列表大小(ArrayList<Integer> 表)     返回表里元素的个数
//   6. static int 列表取(ArrayList<Integer> 表, int i) 返回第 i 个元素
//   7. static void 列表加(ArrayList<Integer> 表, int 值) 把值加进表里
//
// 写法提醒（就这四条，本课的门槛全在这儿）：
//     数组的长度：      a.length          ← 属性，**不加括号**
//     数组取元素：      a[i]              ← 方括号，下标从 0 开始
//     集合的个数：      表.size()          ← 方法，**要加括号**
//     集合取元素：      表.get(i)          ← 方法，不是方括号
//
// 自检：数组长度(new int[]{1,2,3}) → 3；取元素({10,20,30}, 2) → 30；
//   越界了吗({1,2,3}, 2) → false、({1,2,3}, 3) → true、({1,2,3}, -1) → true；
//   新建数组(4) 的四个元素都应该是 0（Java 自动初始化）。
//
