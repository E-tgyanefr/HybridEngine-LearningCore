// 第 03 课：条件判断 —— 让程序会做选择
//
// ─────────────────────────────────────────────────────
//  先介绍：程序要会"分岔"
// ─────────────────────────────────────────────────────
//
// 到上一课为止，程序只会一条道走到黑。但真实的需求几乎都是"看情况"：
// 猜的数字比 42 大就告诉他"大了"；分数够 90 就是"优秀"；
// 今年是闰年 2 月就多一天。条件判断让程序**分岔** —— 同一段代码，
// 不同的数据走不同的路。这是"程序开始像在思考"的第一步。
//
// Java 的条件和别的语言长得差不多，但有**一条特别值得讲**：它对 `=` 和 `==`
// 的检查比 C/C++ 严 —— 可是**只严一半**。
//
//     if (分数 = 3)        编译不过（int 不是 boolean，Java 当场拦住你）
//     if (年 % 4 = 0)      编译不过（报「意外的类型」）
//     if (标志 = true)     **能编译、零警告，而且条件永远为真**  ← 真正的坑
//
// 前两种编译器替学生挡了，第三种挡不住。所以这一课的核心就盯它。
// （这三条都是本机 javac 25.0.3 实测的结果。）
//
// ─────────────────────────────────────────────────────
//  用法与例子
// ─────────────────────────────────────────────────────
//
// ① if / else if / else：从上往下试，**第一个为真的就进去**
//
//     if (分数 >= 90) {
//         return "优秀";
//     } else if (分数 >= 60) {
//         return "及格";
//     } else {
//         return "不及格";
//     }
//
//   ⚠ 顺序是有意义的：95 同时满足 >= 90 和 >= 60，但它在**第一条**就被接走
//     了。所以判断范围要从"最窄"往"最宽"写。分数 = 105 该走哪条？也是这个理。
//
// ② 比较运算符（结果是 boolean：true 或 false）
//
//     == 等于    != 不等于    > 大于    < 小于    >= 大于等于    <= 小于等于
//
//   ⚠ 等于号是**两个**：判断相等用 ==，一个 = 是**赋值**（把右边存进左边）。
//
// ③ 把几个条件连起来：&& （并且）  || （或者）  ! （取反）
//
//     分数 < 0 || 分数 > 100                              ← 越界判断（两头都要写）
//     (年 % 4 == 0 && 年 % 100 != 0) || 年 % 400 == 0      ← 闰年的完整条件
//
//   ⚠ 优先级：&& 比 || 先算。所以上面那层的括号其实可以省，但**写上更好读**。
//
// ④ boolean 变量：先把结论算出来，再用它判断
//
//     boolean 是闰年 = (年 % 4 == 0 && 年 % 100 != 0) || 年 % 400 == 0;
//     if (是闰年) { return "闰年"; }
//
//   好处：条件太长时**读起来清楚**，而且这个结论还能复用。
//   ⚠ 用 boolean 变量时**直接写它**就行：if (是闰年)。写 if (是闰年 == true)
//     也对，但多打一遍就多一次手滑机会（见坑 1）。
//
// ⑤ switch：一个值对好几个固定选项时，比一串 if 清爽
//
//     switch (星期几) {
//         case 1:  return "星期一";
//         default: return "没有这个星期";       ← default 是兜底，建议写上
//     }
//
// ⑥ 方法里每个分支都要能 return —— Java 会检查"所有能走到的路径都有返回值"。
//
// ─────────────────────────────────────────────────────
//  常见坑
// ─────────────────────────────────────────────────────
//
// ⚠ 坑 1：把 == 写成了 =（本课最重要的一个坑，它有**三种下场**）
//
//     if (分数 = 3) { }              ← 第一种
//
// 你会看到：错误: 不兼容的类型: int无法转换为boolean
// 为什么：一个 = 是赋值，`分数 = 3` 这个表达式的类型是 **int**，而 if 的括号
//   里**必须是 boolean**。类型对不上，Java 直接拒绝编译。
//   ✅ 好消息：**这一点 Java 比 C/C++ 严** —— C/C++ 对 if (x = 3) 顶多给个
//      警告（甚至不警告），Java 直接不让你编。
//
//     if (年 % 4 = 0) { }            ← 第二种
//
// 你会看到：错误: 意外的类型   /   需要: 变量   /   找到: 值
// 为什么：= 的优先级最低，这一行会被理解成"把 0 存进 年 % 4"—— 可 年 % 4 是
//   一个**算出来的值**，不是变量，存不进去。
//
//     boolean 标志 = false;
//     if (标志 = true) { ... }       ← 第三种：**编译通过，零警告**
//
// 你会看到：什么都不报，而那个分支**永远会进去**（赋值的结果就是刚存进去的
//   true）。这是 Java 唯一挡不住的那一种，也最危险 —— 程序照跑，结果全错。
// ⇒ 防身三招：① 判断相等一律用 ==；② boolean 变量直接写 if (标志)；
//   ③ 把常量写在左边：if (42 == 猜) —— 手滑写成 = 会直接编译不过。
//
// ⚠ 坑 2：漏了 return，或者分支没兜全
//
//     static String 猜数字(int 猜) {
//         if (猜 == 42) { return "对了"; }
//         // 猜比 42 小、比 42 大的情况都没写
//     }
//
// 你会看到：错误: 缺少返回语句
// 为什么：方法声明了要返回 String，可编译器发现"如果 猜 不是 42，这个方法走到
//   末尾也没交出任何东西"—— 它不允许这种可能。
// ⇒ 用 else 兜住剩下的所有情况，或者最后写一句无条件的 return：
//       if (猜 == 42) { return "对了"; }
//       if (猜 < 42) { return "小了"; }
//       return "大了";                 ← 前面都没接住，那一定是大了
//
// ⚠ 坑 3：switch 忘了 break —— "贯穿"，x = 1 时三行全打
//
//     switch (x) {
//         case 1: System.out.println("一");
//         case 2: System.out.println("二");
//         default: System.out.println("其他");
//     }
//
// 你会看到：什么都不报，只是 x = 1 时把「一 / 二 / 其他」三行**全打了出来**。
// 为什么：switch 的规矩是"**从匹配上的那个 case 开始，一路往下执行**"，直到
//   碰上 break 或者整块结束。这叫 fall-through（贯穿），是设计不是 bug。
// ⇒ 每个 case 结尾加 break;（或者像本课这样直接 return，return 本身就跳出了）。
//
// ⚠ 坑 4：边界写成 > 而不是 >=
//
//     if (分数 > 90) return "优秀";        ← 90 分会掉进下一档
//
// 你会看到：什么都不报，只是 90 分被判成"及格"、60 分被判成"不及格"。
// 为什么：>= 和 > 只差一个字符，意思差一整档。本课的检查专门放了
//   90 / 89 / 60 / 59 这四个数，就是来照这件事的。
//
// ─────────────────────────────────────────────────────
//  轮到你了 —— 在下面写
// ─────────────────────────────────────────────────────
//
// ⚠ 写四个**方法**（不用写 main、不用写 class、不用写 import ——
//   检查时会自动把它们套进 class Main 里调用）。四个都要写 static。
//
//   1. static String 猜数字(int 猜)
//        猜 == 42 → "对了"    猜 < 42 → "小了"    猜 > 42 → "大了"
//
//   2. static String 成绩等级(int 分数)          ← 越界那条用 ||
//        分数 < 0 或者 分数 > 100 → "分数不合法"
//        分数 >= 90 → "优秀"     分数 >= 60 → "及格"     其他 → "不及格"
//      ⚠ 想清楚条件的**先后顺序**：分数 = 105 应该走哪一条？
//
//   3. static String 闰年(int 年)
//        「能被 4 整除 且 不能被 100 整除」或者「能被 400 整除」 → "闰年"
//        否则 → "平年"
//      ⚠ 两件事都要做到：① 用 && 和 || 把条件连成**一个**条件，不要用嵌套 if；
//        ② 先把结果算进一个 boolean 变量，再用这个变量去 if：
//              boolean 是闰年 = (年 % 4 == 0 && 年 % 100 != 0) || 年 % 400 == 0;
//      （整除用 %：年 % 4 == 0 就是"能被 4 整除"）
//
//   4. static String 星期名(int 星期几)
//        用 **switch** 写：1 → "星期一" … 7 → "星期日"；其他 → "没有这个星期"
//      ⚠ 这一课要求必须用 switch（用一串 if-else 也能写对，但那就没练到它）
//
// 边界自己先过一遍：成绩等级 95 优秀 / 90 优秀 / 89 及格 / 60 及格 / 59 不及格；
//   闰年 2024 闰年 / 2023 平年 / 1900 **平年** / 2000 闰年；
//   星期名 0、8、-1 都是"没有这个星期"。
//
